### 角色画法五条铁律（2026-11-03 返工四轮换来的）

1. **脸四件套**：眼球 + 高光白点 + 眉毛 + 嘴。少一个就读成道具；眉毛决定情绪，嘴只决定笑没笑。
2. **手是实心圆**：`arm()` = 两段折线 + 腕上一个实心圆（r 5.6~6.4 s）。不画手的人形像纸片。
3. **手臂色比衣服亮一档**（王子 `#4E7191` / 公主 `#A8D4EC` / 国王 `#41608A`）。同色 = 手臂被身体吃掉，只剩两个橙点。
4. **头发先画发球再画脸**：发球 r = 脸 + 3~4px，脸圆心下移 2~3px；脸圆盖住发圆就是秃。
5. **胡子分两件**：八字胡 + 下巴胡，中间留出嘴。一整把盖住下半脸 = 没表情。

### 尺寸就是语义（2026-11-04 补）

同一个素材换个 `s`，讲的是完全不同的两件事，**这比画得好不好更重要**：

| 场景 | 本体 | 对手 | 读出来的意思 |
|---|---|---|---|
| NO.21 开场 龙抓公主 | 公主 `s=1.9`（高 295） | 龙 `s=0.95`（高 285） | ✗ **一样高** → "两个人并排站着" |
| 同上改后 | 公主 `s=1.9` | 龙 `s=1.45`（高 435） | ✓ 高出一头 → "恶龙把公主拎走了" |
| 门景里的龙 | 门高 560 | 龙 `s=0.8`（高 240） | 背景角色，不抢守卫的戏 |

**判据：吃人的 / 抓人的 / 威胁的，视觉高度 ≥ 受害者的 1.4 倍。** 不然观众读成合影。

配套手法：主体移动之外再撒 5~8 个逃逸粒子（碎石、尘），"动势"才立得住。

### 恶龙：不要手写大闭合路径

前两版都用一条 path 画整只龙（尾→背→颈→头→吻→喉→胸→腿→地面），结果头没形状、脖子过长、
骨刺飘出轮廓、牙落在嘴外，而且改一处牵连十处。

现在改成**部件拼装**：身体椭圆 / 脖子弯管 / 头圆 / 吻梯形 / 腿圆角柱 / 尾 / 翼各自独立闭合，
两两重叠 ≥ 20px 把接缝埋进去。沿轮廓排布的装饰**用公式取点**，不要手写坐标：

```js
const spineY = (px) => BODY.cy - BODY.ry * Math.sqrt(1 - ((px - BODY.cx) / BODY.rx) ** 2);
```

验图**按成片实际尺寸**截（s≈1.15，画面里约 300px），别放大 2 倍 —— 放大看的是成片里不存在的接缝。

## 二·五、纸戏素材（`web/js/props_grid.js`，2026-11-04 为 NO.22 建）

> 为什么单独一个文件：这期全片只有"一张方格纸"。通用画材画不出来 ——
> **纸剪开以后，块上还得有格线**，否则观众看不出"还是那四块纸"，只会觉得"四张彩纸"。

| 画材 | 干什么 | 关键参数 |
|---|---|---|
| `sheet` | 整张方格纸 | `x,y,cell,cols,rows` · `setOn(r,c,q)` / `rowPulse` / `colPulse` |
| `poly` | **带格线纹理的多边形拼块**（clipPath 把格线裁进多边形） | `pts`（格坐标）, `cell`, `tone:"A/B/C/D"` · `move/setRot/setFlip` |
| `cut` | 虚线切线 | `pts, scale` · `draw(p)` **沿折线切成 N 段短虚线逐段点亮** |
| `scissors` | 剪刀 | `snip(q)` 开合 · `move(x,y,angle)` |
| `loupe` | 放大镜框（不真放大，只做指向） | `x,y,r,angle,s` |
| `tally` | 计数条（n 个小方块） | `run(p)` 顺序点亮 · `setOn(i,q)` |
| `eye` | 一只眼睛 | `blink(q)` · `look(dx,dy)` |
| `slope` | 斜率对比条（两条斜边 + 水平基准） | `x,y,w,h1,h2` |
| `seam` | **一条缝**：有填充的窄带，宽度可张开 | `pts`（四个角）, `width` · `setWidth(k)` |

三条踩过的坑：
1. **`cut` 不能靠改 `stroke-dasharray` 做"逐步露出"** —— 那会把虚线本身改成实线。
   只能沿折线切成 N 段短虚线，逐段改 opacity。
2. **`seam` 不能画成一条线** —— 线没有面积，观众不会相信它能攒出一格。必须有填充带。
3. 纸的四档明度 `A #EAF2FF / B #D5E1F0 / C #C0D0E2 / D #ABBDD2`，四块拼块靠它区分"还是那四块"。

### 缺角谜题（8×8 → 5×13）的硬数据（画面照这个画，不用再推）

| 项 | 值 |
|---|---|
| 正方形 / 长条 | 8×8 = **64** ／ 5×13 = **65** |
| 大三角 | 竖 3 横 8，斜边 √73，斜率 **0.375** |
| 小三角 | 竖 2 横 5，斜边 √29，斜率 **0.400** |
| 斜率差 | **0.025**（夹角 1.24536°） |
| 缝的形状 | 平行四边形，顶点（长条左下为原点）：**(0,0) (5,2) (13,5) (8,3)** |
| 缝的四条边 | √29（小三角斜边）· √73（大三角斜边）· √10 · √194（长条对角线） |
| 缝的面积 | 鞋带公式 = **1** |
| 数学底 | 斐波那契恒等式 `F(n)² − F(n−1)·F(n+1) = (−1)ⁿ`，`64 − 65 = −1` |

★ **不要写 A4 纸**：A4 是 210×297 的长方形，装不下"八格见方"。必须说"正方形的纸"。

**判据（五条，任一不满足就不许开作画）**

1. `06_画面绘制.md` 里存在 `## 素材盘点` 章，且三张表都在。
2. 表 B 每一行「入库状态」都是 `✅ 已入库`；出现 `⚠️ 描述不足`、空白、或"待补"都算没做完。
3. 图类新增：`20 素材_只读/graphics/` 里有这个文件，且 `graphics_catalog.json` 的 `items` 里有对应条目。
4. 画材类新增：本期 `web/js/props_<主题>.js` 里有这个函数，且单独抽帧看过（比例/锚点/包围盒）。
5. 音效：`sfx_catalog.json` 里能查到 id；`scenes.js` 里出现的每个音效 id 都必须查得到（查不到就是 mux 静默跳过）。

**入库方式**

| 类型 | 存哪 | 登记到哪 |
|---|---|---|
| 图（SVG） | `20 素材_只读/graphics/<名字>.svg` | `graphics_catalog.json` → `items` 追加 `{id,name,group,tags,viewBox,body}` |
| 画材（代码） | 本期 `web/js/props_<主题>.js` | 不需要登记，`define()`/导出名即身份 |
| 音效 | `20 素材_只读/sfx/<id>.wav` | `sfx_catalog.json` → `sounds` 追加 `{id,category,duration,sync_at,lufs}` |
| 音乐 | `20 素材_只读/bgm/` | `bgm_catalog.json` |

**常见四种"以为库里有、其实没有"**
