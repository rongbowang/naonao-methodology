# 工具清单（`02 工具/`）

## 文案阶段

| 脚本 | 用法 | 作用 |
|---|---|---|
| `check_style.py` | `<script.py>` | 禁词 / 编排话（`METATALK`，硬 FAIL）/ 人称 / 匀速 / 爆点 / 片尾 |
| `_humanize.py` | `<script.py>` | 口播 AI 味 0~10 分（≤4 才过）：排比 / 升华 / 解释腔 / 锚点 / 毛边 / 节奏 |
| `gen_cues.py` | 在期目录跑 | `script.py` → `cues.json` |

## 配音 / 时间轴

| 脚本 | 用法 | 说明 |
|---|---|---|
| `tts_whole.py` | `--mode all --engine minimax --out audio --fresh` | MiniMax 付费配音；音色读 `02 工具/_tts_key.json`（`presenter_male` / 1.16） |
| `gen_timeline.py` | 在 `web/` 跑 | 读 `web/size.json` 定画布，输出 `timeline.json` |
| `build_voice.py` | 在 `web/` 跑 | `audio/` → `voice.wav`（**必须在 mux 之前跑**） |

## 渲染

| 脚本 | 用法 | 说明 |
|---|---|---|
| `render_all.py` | `NO.19 [NO.20 ...]` 或 `--mux-only` | 段渲染 → 拼片 → build_voice → mux → 交付 → 封面 |
| `capture.mjs` | 由 render_all 调 | viewport 读 `timeline.json` 的 width/height；**固定 8130 端口** |
| `mux.py` | `[输出名]` | 画面 + voice + bgm + sfx；含 `SFX_ALIAS` 别名表（防音效名写错静默跳过） |

## 封面 / 归档

| 脚本 | 用法 | 说明 |
|---|---|---|
| `_covers.py` | `<期>` `--out <交付目录>` | 5 版 × 3 比例；文件名取 `covers.json` 的 `title` |
| `_archive.py` | `<日期> <NO.xx> <标题> <目录名>` | 归到 `40 出版物/` |
| `_verify.py` | — | 守门：期号唯一 / 四件套齐 / 素材只读 |

## 体检

| 脚本 | 位置 | 判据 |
|---|---|---|
| `_bbox.mjs` | `web/` | 越界 / 压线(760~800) / 压字幕(>800) |
| `_alive_pre.mjs` | `web/` | 最长静止 <4s（渲染前，省一次 15 分钟） |
| `_alive.py` | `02 工具/` | 同上，输入成片 mp4 |
| `_check/_gcheck/_overlap` | `web/` | 出画 / 压字 / 互压 |
| `_dupcheck/_wcheck/_outro` | `02 工具/` | 复读 / 锚点匹配 / 片尾完整 |
| `_humanize.py` | `02 工具/` | 口播 AI 味 |

## 本次新增

- `_humanize.py`（2026-11-03）：因为通用 `ai-taint-score.js` 只认"首先/其次"，
  对中文口播打 0 分却满屏 AI 味，所以自建六项打分器。
- `mux.py` 的 `SFX_ALIAS`：把场景里"想当然"的音效名映射到 `sfx_catalog.json` 的真实 id。
