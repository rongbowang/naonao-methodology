# 目录与交付（唯一标准）

## 一、顶层（Johnny.Decimal）

```
00 规格与决策/     product / 一期规格 / 验收 / 设定自洽 / adr / 本 skill
01 操作手册/       工作流 / 制作口诀 / 文案踩坑记录 / 素材库总表 / 配音方案
02 工具/           所有脚本（唯一入口 _paths.py）
10 内容/           选题库 / 方法论（文案创作法）
20 素材_只读/      bgm / sfx / fonts / graphics（**只读，写入会 PermissionError**）
30 制作/<YYYY-MM-DD_标题>/   工程（期号不进路径）
40 出版物/<日期>/<NO.xx_标题>/   ← 用户只看这一层
99 归档/           一切"曾经是现在不是"
```

## 二、工程目录（30 制作/<YYYY-MM-DD_标题>）

只允许这些文件：
```
00_立项单.md
script.py              文案唯一来源（改台词必须从 gen_cues.py 重走）
05_剧本_送审.md         送审稿
06_画面绘制.md          画面文档（19 项 + 4 个量化栏位）
covers.json            封面文案（title 决定交付文件名里的标题）
cues.json              配音逐句
tts_whole.py           本期配音脚本
web/                   渲染工程
```
其余（`*.orig`、`*.old_*`、`_concat*`、`_seg`、`_tmp*`、`tts_resume.py`）一律进 `99 归档/`。
`05_剧本_送审.md` 存在时，旧的 `05_剧本.md` 归档。

## 三、出版物目录（用户看的唯一一层）

```
40 出版物/2026-11-03/NO.19_地球加长一米/
    NO.19_地球加长一米_横屏.mp4          1920×1080 成片
    封面_NO.19_十六厘米.png              竖版 1080×1440
    封面_NO.19_十六厘米_横版.png          横版 1440×1080
    封面_NO.19_十六厘米_16x9.png          16:9 1920×1080
    标题与描述_NO.19_地球加长一米.txt
    封面候选/                            其余候选（9 版×3 比例）
```

**铁律**
1. 日期目录下**只有期目录**，不许散落 mp4、`_旧版备份/`、`Thumbs.db`
2. 一期目录里**只有成片 + 3 张终选 + 标题描述 + 一个 `封面候选/`**
3. 交付文件名取 `covers.json` 的 `title`（大字），不取目录名 —— 否则重新渲染会把改名冲回去
4. 一天一期；同一天多做一支，往后顺延日期，不许塞进同一个文件夹

## 四、归档（99 归档/）

| 目录 | 放什么 |
|---|---|
| `_旧文档/` | 旧剧本、旧画面文档、旧 scenes.js |
| `_旧段_<说明>/` | 渲染分段（改画面后挪走，防断点续跑用旧帧） |
| `_封面候选_NOxx/` | 候选封面 |
| `_旧版_4x3成片/`、`_旧版_<日期>竖屏/` | 旧画幅成片 |
| `_待删_<日期>/` | 清理出来的临时件，用户确认后可整包删 |

## 五、期号与命名

- 期号 = 发布日顺延，`NO.19` / `NO.20` …
- **期号只写在 `script.py` 的 `NO` 字段里，不进路径**
- 工程目录名 `YYYY-MM-DD_标题`（2026-11-05 起；日期 = 发布日，标题 ≤6 字）
  —— 例：`30 制作/2026-11-01_一百个人等一句话/`
- 出版物子目录名仍为 `NO.xx_标题`；交付文件名仍以 `NO.xx_` 开头
- 封面大字取 `covers.json` 的 `title`（≤6 字，**G 版大字只放得下 4~5 字**）
