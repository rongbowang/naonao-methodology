# 文案规则（细则）

> 主文件 `SKILL.md` 第 3 节是摘要，这里是可执行的判据。

## 一、爆点先于一切（3.0）

动笔前先回答「这个题材的爆点是什么」——**找不出爆点就换题**。
爆点 = 让人第一反应"真的假的"的**具体事实**，必须能说出口（不是话题、不是评价）。

三问全过才立项：① 说给陌生人会「啊？」 ② 第二反应「不可能吧」 ③ 能一眼画成画面。
六型：P1 荒谬事实 / P2 权威翻车 / P3 常识背叛 / P4 数字离谱 / P5 小人物逆袭 / P6 身份错位。
**一期只允许一个主爆点**，写在 `script.py` 顶部 `BAODIAN` / `BAODIAN_TYPE`。

## 二、开场三条（2026-11-03 最终版）

1. **禁钩子句式**：不要「你敢信吗 / 你知道吗 / 你可能不信」。
2. **禁编排话**：不要「先把规矩说死 / 先说结论 / 关键在这儿 / 还有一层 / 举个例子 / 换个问法」。
3. **直给 + 倒计时**：场面 → 规则 → 你的限制 → 逼问 →「给你三秒钟」→ 3 秒 3-2-1（鼓点，不念数字）。

判定口诀（用户原话）：**只要句子在说"我要开始讲了"，不在讲这件事本身，就删。**

## 三、三条老硬规则

1. **禁第一人称感受**：冲击力只由数字对撞、画面、把观众卷进来（你）承担。
2. **禁第一人称实验背书**：「我们真跑了一遍」→ 让结果当主语。
3. **讲成故事，不要蹦豆子**：每句回答「谁 + 做了什么 + 结果」，句间用口语承接（可他/结果/于是/最后/反倒）。

## 四、去 AI 味五刀（2026-11-03 起固定一步）

| 刀 | 干什么 | 例子 |
|---|---|---|
| 删套话 | 首先/其次/值得注意的是/由此可见 | 直接删 |
| 破排比 | "一X一Y""不是A是B""都…都…" | 三连砍成一击，或改成不对称说法 |
| 斩升华 | 段尾"让我们…""这不仅是…" | 换成具体动作或短句留白 |
| 加毛边 | 口语词、破折号插入语、身体动作 | 差一点、偏偏、呢、吧、手搭上去 |
| 变节奏 | 打断 5~10 字的连排 | 连续 6 个以上必须塞一个 ≥11 字或 ≤4 字 |

**机器判据**：`02 工具/_humanize.py` 六项打分，**≤4 才许送审**。
- 对称排比 每处 +1.2 · 强行升华 每处 +1.5 · 解释腔 每处 +0.8
- 具体锚点 <6 处 +2.0 · 口语毛边 <3 处 +1.5 · 最长匀速段 ≥6 或句长标准差 <2.6 +1.5

用户点名保留的表达（例如"人生巅峰"）在 `script.py` 写 `HUMANIZE_OK = [...]` 豁免。

## 五、"试了发现不行"的段落怎么写

- ✗ `可你分不清他是哪一个，这句是真是假说不准。`（一句话带过，观众没看见"不行"）
- ✓ 两情形各算一遍：`门是活的，说真话的会答通，说谎话的必须答不通…门是死的，说真话的会答不通，说谎话的偏要答通…同一句通，两条都对得上。`
- ✓ 或写成心里预演：`差一点就回头问…可这个能字，你验不了。`

## 六、片尾（固定三句，一句不能少）

```
恭喜你，第 N 个知识装进脑子了。          ← 必须有宾语
下一期我们来看：<下期主题改成的问句>      ← 18~30 字，不许直接放答案
关注 脑脑不老佬，明天继续涨脑子。          ← 说这句时上脑子动画
```
每期必跑 `_outro.py`（漏 `brainImgPlay` = 一个不动的脑子，其它体检查不出来）。

## 七、篇幅

- 数理推理类：S 档 100~130 秒 / M 档 150~170 / L 档 180~220
- 旁白 430~650 字；`check_style` 硬上限 680 字
- presenter_male 实测约 5 字/秒（4.2 是保守估计）
- 压缩顺序：砍补充章节 → 砍考证过程 → 合并同义段 → **最后才动句子**（只整段删，不在例子里删成分）
