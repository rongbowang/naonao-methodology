# 画面母版（可复用构图）

> 写画面文档时先来这儿找：这一镜是不是可以用一个现成母版。用母版能省掉一半的坐标推导，
> 而且保证同一支片子里同类信息长得一样。用过的母版要在这页下面记一行（哪一期、哪一镜）。

## 母版 01 · 2×2 交叉表（"两种可能都成立"专用）

**用途**：证明"这个问法没用"——把四种组合一次摊开，观众自己看见四格都亮（= 没有信息量）。
2026-11-03 用户点名要这个形式。

### 画布（1920×1080）

| 部件 | 位置 | 尺寸 | 说明 |
|---|---|---|---|
| 表体 | x 760 → 1740，y 240 → 720 | 980 × 480 | 左侧留 760 给主体（王子/门） |
| 列标题 | y 200 | 字号 44 | 横轴两列：**说真话** / **说假话** |
| 行标题 | x 700，右对齐 | 字号 44 | 纵轴两行：**门真能开** / **门打不开** |
| 单元格 | 2 × 2，每格 440×200，间隔 24 | rx 18 | 底色 `#12263E`，描边 `#2C4762` 3px |
| 格内主角 | 每格中心偏左 | 头像 s=0.8 | 守卫头像（同一个图形，靠边色区分真假） |
| 格内答案 | 每格右侧 | 字号 56 | 「能」/「不能」，格亮时变金色 |
| 贯穿线 | 表格外框 | 3px 虚线 | 提示"四格属于同一个问题" |

### 状态（三拍）
1. **t0 铺表**：外框先画，四格空着（只有守卫头像）
2. **t1 落答案**：四格依次填上「能 / 能 / 不能 / 不能」（顺序：左上→右上→左下→右下，每格 0.12s）
3. **t2 全亮**：四格同时亮同一色 → 观众看到"四种组合全都成立" → 加一行小字「四种都成立」

> 关键：**四格必须同时亮、同一个颜色**。如果两种颜色，观众会以为分出了胜负，反而不懂。

### 换问法后的复用（同一张表，第二拍）
同一个表格留在画面上，问题换成「他会说这扇门能开吗」：
四格的答案依次翻转 → 变成「不能 / 不能 / 能 / 能」→ 四格塌缩成**一张卡片**（320×160，居中）
→ 卡片上只有一个词（不能）→ 卡片用箭头指向左边那扇门。

**两次的对比就是这一期的论点**：第一张表四格全同色（有用信息为零），第二张表四格塌成一句（唯一答案）。

## 母版 02 · 石头拱门（本期门的标准画法）

- 外形：**下方矩形 + 上方半圆**（拱门），不是纯圆、不是尖顶
- 石材：3 道横向石缝 + 拱顶 5 块楔石（key stone 居中最宽）
- 门缝：右缘留 6% 竖缝，`setLit(1)` 时从缝里透暖光（通向公主那扇）
- 深色那扇：`setLit(0)` + 内侧再加一层纯黑（读成"没有底"）
- 门牌：拱顶正中一块方形石刻，写数字（NO.20 复用）
