## 三、守门脚本 `_verify.py`（2026-10-31 补的）

第一版这张表第三节写的 5 条「没人管」，现在全部收进 `_verify.py`。
用法：

```
python _verify.py                # 全库
python _verify.py NO.20_蒙提霍尔  # 单期
python _verify.py --baseline     # 重建素材基线（改过素材后用）
```

| # | 原来没人管的 | 现在怎么验 |
|---|---|---|
| 19 | 期号唯一性 | 扫 `30 制作/` 与 `40 出版物/`，同一 `NO.xx` 不许出现在两处；**目录名必须以 `NO.xx_` 开头且与 `script.py` 的 NO 一致**（ADR-0001） |
| 20 | 交付四件套 | `40 出版物/<日期>/` 必须有 `_竖屏.mp4` + 封面三版 + `标题与描述_*.txt` |
| 21 | 素材只读 | `20 素材_只读/` 比对 `_baseline.json` 的 mtime+size，被改被删都报 |
| 22 | 工程与归档一致 | `script.py` / `scenes.js` 的 mtime 晚于已发布成片 = 改了没重渲 |
| 23 | 立项单 | 每期必须有 `00_立项单.md`，且开头写「遵循：01 一期规格 vX」 |

**2026-10-31 首次跑的结果**：5 项里 4 项当场通过，抓出 8 处真问题
（3 个目录名 vNN 与期号不符 / NO.19 改了台词没重渲 / 4 期缺立项单），已修 7 处。
剩下 1 处 `NO.19 script.py 比成片新` 是真问题，等 NO.20 定题后重渲对齐。
