## A. 结构：九段式

按顺序，比例只做参考，冲突时以「讲得顺」优先。

| # | 段 | 任务 | 常见病 |
|---|---|---|---|
| ① | 处境 | 把题装进一个动作，观众正在做 | 一上来讲知识 |
| ② | 规矩 | 规则 ≤15 秒讲完，**必须堵死一条捷径** | 规则没讲清就开始算 |
| ③ | 立靶 | 让观众自己说出错答案 | 直接给答案 |
| ④ | 背书 | 这事有人认真算过（人名/年份/规模） | 空洞地说「很多人」 |
| ⑤ | **绝望** | **证明这根本做不到**（算给观众看） | 只报状态，不验算 ← 最常见 |
| ⑥ | 转折 | 报出要走几步 | 跳步 |
| ⑦ | 破执念 | 指出直觉错在哪个具体环节 | 泛泛说「反直觉」 |
| ⑧ | 解法 | 带数字算一遍，**再换个数字验一遍** | 只算一次不验 |
| ⑨ | 收尾 | 落到观众今天会做的一件事 | 升华、喊口号 |

**判据**：关掉视频，能不能三句话讲给旁边的人。

## B. 文案硬规则（违反必退稿）

1. **禁第一人称感受**：「我愣住了」「我看完后背发凉」。冲击力只由数字对撞、画面、把观众卷进来承担。
2. **禁第一人称实验背书**：「我们真跑了一遍」。让结果当主语。真写了就必须真做过。
3. **人称阈值**：「你」≥5 次；「我/我们」≥1 次（只允许两种用法：泛指共识 / 转述结论）。
4. **禁蹦豆子**：每句回答「谁 + 做了什么 + 结果」；不许连线 6 个逗号级小句都落在 5~10 字。
5. **每句 ≤16 字断行**：超过会在字幕里断出「次。」这种孤行。
6. **片尾固定三句**：
   ```
   恭喜你，第 N 个知识装进脑子了。        ← 必须有宾语
   下一期我们来看：<问句>                 ← 剔前缀后 18~30 字，且与下期钩子不重样
   关注 脑脑不老佬，明天继续涨脑子。
   ```
7. **同一件事不许讲两遍**：单句都合格也可能整段重复，靠结构审查抓。

## C. 画面规则

1. **画材 ≤3 种，全片不换**。观众看的是「同一个东西在变」。
2. **一个道具从头用到尾**，状态迁移 = 叙事推进。
3. **动效要有面积**：大面积扫光 / 数字滚动 / 粗环呼吸 / 整块填充。5px 波纹、小圆点、1.02 倍呼吸在缩略图里量不出来。
4. **动作三段式**：举起 → 悬停憋住 → 在台词那一拍落下。打击点必须咬住台词点。
5. **文字底边 ≤1104**（字幕区上沿 1170）；开镜头放大后只排到 990。
6. **抽象形状必须有载体 + 动词**：说「点头」就真点。

## D. 音频

- 音色 云扬 `zh-CN-YunyangNeural`，rate `+8%`
- **整段合成**（`tts_whole.py`），不用逐句拼——逐句拼=播报腔，换音色救不了
- 时间码取 edge-tts 的 `SentenceBoundary`（实测），不靠静音猜
- 成片响度 −18.5 LUFS，BGM 垫到旁白 −10dB，不挂 sidechain

## E2. 改稿规则（2026-10-31 用户定）

1. **只有一份文案**：`script.py` 是真身，导出物固定叫 `文案.md`，改了就地覆盖。
2. **不许一版一版往上加**：不写 `文案_v3`、`_v5`、`_final` 这类文件。
3. 用户说改哪一句，就直接在 `script.py` 里改那一句，然后重导 `文案.md`（一条命令）。
4. 真需要留旧版，我自己挪进 `99 归档/旧文案_<期号>/`，**不放在工程目录里**。

## F. 变更影响表

改哪一处，必须重跑什么。**这条是为了防「改了台词忘了重配」**。

| 改了 | 必须重跑 |
|---|---|
| `script.py` 任意一句台词 | `gen_cues` → `tts_whole --fresh` → `gen_timeline` → `build_voice` → 全片重渲 |
| 只改 `scenes.js` 画面 | 全片重渲（配音不动） |
| 只改片尾三句 | 同上「改台词」 |
| 改封面文案 | 只重出封面 |
| 改 01/02 规格 | 不重跑任何片子；**已发布的按当版验收，不追改** |
