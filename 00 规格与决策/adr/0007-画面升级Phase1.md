# ADR-0007 画面升级 Phase 1：资产库 + 音效轨 + 文档对账

- 日期：2026-11-01
- 状态：已执行（NO.17 两镜样板跑通）
- 依据：`00 规格与决策/画面升级诊断与改造方案_2026-11-01.md`

## 背景

诊断结论：技术栈（SVG + puppeteer）保留，要换的是"画什么"，并且让 `06_画面绘制.md`
真正变成唯一画面真相。三个断点：① 没有角色/场景资产，只能画几何图形 ② 只有旁白+BGM，
无音效 ③ 文档产出后没有被 scenes.js 逐栏执行。

## 决定

### 一、美术资产库 `js/assets.js`

- 位置：`02 工具/_webtmpl/js/assets.js`（模板库，新期派生自动带上）。`index.html`
  在 `lib.js` 之后、`scenes.js` 之前加载。
- 出口：`window.ASSET`。ID 命名 `<类>/<名>`，类为 `char`（角色）/`scene`（场景）/
  `prop`（道具）/`fx`（特效）/`mood`（氛围）。
- 铁律不变：**资产只建 DOM + 暴露可动部件，动画由场景 update 每帧驱动**（t 的纯函数）。
  需要自身节奏的（篝火/水花/雪花）返回 `update(t)` 交给场景调。
- 人形硬指标：2.75 头身；肩宽 = 1.55 × 头直径；手 = 实心圆；必须有脚和描边。
  表情 4 种（calm/shock/grave/set）+ 姿态 4 种（stand/walk/leap/sit）。
- 眼睛发光必须用**径向渐变**（`eyeGrad`）。平涂圆看起来是"红脸"不是"发光"。

### 二、音效轨（第三轨）

数据链（四段，缺一段音效就静默消失）：

```
script.py 每镜 "sfx": [
  {"t": 镜头内秒, "name":..., "vol":...}                  # 氛围轨
  {"line": i, "at": 相对句首秒, "name":..., "vol":...}     # 动作点
]
  ↓ gen_timeline.py 摊派
timeline.json 每句 lines[i]["sfx"] = [{"t": 镜头内秒, ...}]
  ↓ scenes.js build（两镜各一份）
(shot.lines||[]).forEach(L => (L.sfx||[]).forEach(s => LIB.sfx(box, s.t, s.name, s.vol)))
  ↓ engine.__collectSFX() 转全局秒 → capture.mjs 写 sfx.json
  ↓ mux.py 第三轨（sync_at 对齐峰值 + LUFS 归一 + amix）
成片
```

- **音量口径**：`TARGET_SFX_LUFS=-19`，实际响度 = `-19 + 20log10(vol)`。
  要求"垫在旁白(-20)下方 −12~−16 dB" → `vol ∈ [0.14, 0.224]`。
  氛围音（海风）取下限，动作音（入水）取上限。
- **自定义音效**放期根 `sfx_custom/`，元数据 `sfx_custom_catalog.json`（sync_at + 实测 LUFS）。
  `mux.py` 查找顺序：期根 `sfx_custom/` → 共享 `20 素材_只读/sfx/`。
- 合成脚本：`02 工具/mk_sfx.py`（numpy，无外网依赖）。短音效（<3s）量 LUFS 必须
  重复拼接 8 次再量，否则 loudnorm 给 `-inf`，mux 归一计算会炸。

### 三、文档对账（强制）

`scenes.js` 每一镜必须能**逐栏对应**回 `06_画面绘制.md` 的「画面 / 元素 / 动效」三栏。
对应方式写在文档末尾的**对账表**里（文档项 → scenes.js 函数/行 → 状态）。
对不上 = 该镜未完成，不得进入配音与渲染。

- 时间锚**从 timeline 读**，不硬编码：`const L3 = shot.lines[3].g0 - shot.start`。
  硬编码秒数在台词一改就全错。
- 实现里若用 `W(shot,i,"词")`，改台词必须跑 `_wcheck.py`（词找不到会静默失效）。

### 四、其他

- 底色按内容走：剧情镜深色（`window.LIGHT=false`），推演镜可浅色。**期内统一**。
- 转场：timeline 两镜首尾相接（`shot1.end == shot2.start`）→ engine 走 `in` 分支 = 硬切；
  剧情点可在下镜开头 0.3s 叠 `fx/snow_noise`。
- 音效资产 ID 与画面资产 ID 分开记（音频在 `sfx_custom_catalog.json`）。

1080×1440/30fps，935 帧，9 个音效点，console 零报错。

## 没做的（Phase 2）

- 资产库只建了岛民/夜色海岛/码头/篝火/水花——守卫、老板、旅馆走廊、会议室、电梯还没建。
- NO.17 其余 9 镜、NO.18~23 全部仍按旧示意图实现。
- `gen_docs.py` 的模板仍是「人物/道具/逐句动作」v2 格式，未改成「画面/元素/动效」三栏。
- 雪花噪点目前每帧改 feTurbulence seed，9 帧内可用；若要用更长需换预渲染噪点序列。
