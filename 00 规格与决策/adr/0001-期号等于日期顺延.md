# ADR-0001 · 期号 = 日期顺延

- 状态：已采纳
- 日期：2026-10-31
- 触发：用户质问「怎么都排到五十多号了？10月30号是第几个？」

## 背景

旧方向 NO.01~NO.20 是 10-15~11-03 一天一期。换赛道后我按「新方向第几条」
自己编成 NO.51 / NO.52，于是同一批内容出现了 51、17、53 三个号，
归档目录顺序变成 53 → 51 → 52，片尾「第 53 个知识」比「第 52 个」更早播出。

## 决定

期号 = 上一条 + 1，**与发布日同步**，不另设序号体系。
10-30 是 NO.16，10-31 就是 NO.17。

## 后果

- 目录名、交付文件名、片尾台词、封面编号，四处必须是同一个号
- 改期号要连目录一起改；**一个编号一生只给一期用**
- 哪天断更，期号照常 +1，日期跳到下一个发布日
