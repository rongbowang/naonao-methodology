# 00 产品规格

> 版本 v1 · 2026-10-31 · 改这份要记 ADR
> 这份回答「账号是什么」。它下面才是「一期视频长什么样」（01）、「怎么算合格」（02）。

## 1. 一句话

「脑脑不老佬」是一个**让人先算错、再算对**的短视频账号。

知识科普是我告诉你一个事实、你点头；我做的是我给你一个条件、你自己想答案。
区别在观众的姿势——一个在听，一个在想。**第一秒他就已经参与进来了。**

## 2. 观众

- 刷到时会想「这题我会」的人。
- 判断成功的唯一标准：**看完会不会转述给旁边的人**。转述不了，这条就废了。

## 3. 一期的定义

| 项 | 规格 |
|---|---|
| 形态 | 竖屏 1080×1440 / 30fps |
| 时长 | **讲完为止，不设上限**（ADR-0002） |
| 结构 | 九段式（见 01 一期规格） |
| 交付物 | `final.mp4` + 封面 ×3（竖/横/16:9）+ 标题与描述.txt |
| 节奏 | 一天一期，期号 = 上一条 + 1，**与发布日同步**（ADR-0001） |

## 4. 选题准入（四条，任一不过就换题）

1. 规则一句话讲完（≤15 秒）
2. 答案是一步（一个动作，或一句话）
3. **观众手边有东西能试**
4. 答案能三句话转述给朋友

第 3 条最容易被忽略，但它决定「看完会不会自己动手」。

## 5. 分工（谁定什么）

| 事 | 谁定 |
|---|---|
| 选题 | 我出候选（每批 5 个，带一句话钩子和难度）→ **用户圈** |
| 钩子（00 镜首句） | **我写**（2026-10-31 用户授权全权改动）。按竞品结构：结果前置 / 遗书体 / 反常识，样本见 `10 内容/竞品/` |
| 片尾预告 | 我写，必须与下一期实际内容对应 |
| 期号 / 发布日 | 我排，改了要报 |
| 规格本身 | 用户点头才改，改一次记一条 ADR |

## 6. 明确不做

- 不做「我告诉你一个事实」型的纯知识科普（旧方向，已归档）
- 不用第一人称感受（「我愣住了」）做冲击力
- 不用「研究表明」「教科书上说」开头
- 不做没有可验证答案的玄学题

## 7. 命名铁律

- 期号 `NO.xx` **一生只给一期用**，改期号必须连目录名一起改，不允许同一编号出现两次
- 交付文件名固定：`NO.xx_<标题>_竖屏.mp4`、`封面_NO.xx_<标题>{,_横版,_16x9}.png`、`标题与描述_NO.xx_<标题>.txt`
- 脚本里一律用 Python 路径 API，**禁止在 cmd 里操作中文路径**（UNC + 中文 cmd 会挂）
