# 02 工具

所有能跑的代码都在这。目录 2026-10-31 由 `工程文件/` 改名而来。

## 管线顺序（一期跑完只需一条命令）

```bash
python _run.py <期目录名>          # prep → cues → tts → timeline → voice → capture → mux
python _run.py <期目录名> --no-tts  # 台词没改、只重渲画面时用这个（省 40 秒）
```

## 各脚本管什么

| 组 | 脚本 | 作用 |
|---|---|---|
| 路径 | `_paths.py` | **唯一路径入口**，新旧位置都找得到；别的脚本不许自己拼路径 |
| 文案 | `check_style.py` `_review.py` | 句子层 / 结构层两道检查 |
| 画面 | `_check.mjs` `_overlap.mjs` `_gcheck.mjs` `_wcheck.py` `_dupcheck.py` `_alive.py` `_deadshot.py` | 出画 / 压字 / 锚点 / 复读 / 静止 |
| 音频 | `tts_whole.py`（复制到每期根目录用） | 整段合成 + SentenceBoundary 取时间码 |
| 交付 | `_covers.py` `_archive.py` | 封面 5 版 ×3 比例 / 归档四件套 |
| 环境 | `_doctor.py` `_smoke.py` | 换机器后先跑这两个 |
| 文件 | `_rw.py` `_prep.py` `_mkwork.py` | 只读绕过 / 产物让位 / 整期复制 |
| 模板 | `_webtmpl/` | 每期脚手架，`newep.py` 从这里派生（生成到 `30 制作/`） |
| 素材 | `_lib/` `_dy_*.mjs` `_art_trace.py` | TTS 内置模块 / 抖音抓取 / 描摹 |

## 两条铁律

1. **不许再硬编码路径**。要用目录就 `from _paths import WORK, PUB, ARC, ASSETS, proj_dir`。
2. **素材只读**。`20 素材_只读/` 任何人（含我）不写；`mux.py` 用 `_find_up()` 往上找 BGM 和音效。
