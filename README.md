# 脑脑不老佬 · 科普短视频生产方法论

科普短视频账号「脑脑不老佬」从选题到成片的标准化生产方法论与工具管线。

本仓库**只收录可复用的方法论与工具源码**，不含具体成片、素材库与渲染产物。

## 目录结构

| 目录 | 内容 |
|---|---|
| `00 规格与决策/` | 产品规格、验收规格、ADR 决策记录、`naonao-production` skill 与 references |
| `01 操作手册/` | 工作流、制作口诀、配音/画面/素材规范、交接文档 |
| `10 内容/方法论/` | 叙事结构法、文案创作法、画面生动性、运镜配方等 18 篇方法论文档 |
| `02 工具/` | 生产管线脚本（`.py` / `.mjs` / `.js` 源码与配置） |

## 工作流概览

选题 → 文案 → 去 AI 味 → 送审 → 画面文档 → 送审 → 配音 → 作画 → 体检 → 渲染 → 封面 → 归档。

## 说明

- 实际产出（成片、封面、渲染帧、素材）在本地工程中，不进入本仓库。
- `02 工具/` 仅为脚本源码；密钥、缓存、样例素材、构建产物均已通过 `.gitignore` 排除。
