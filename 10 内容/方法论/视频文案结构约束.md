# 视频文案结构约束（70~90 秒科普口播）· 2026-10-23

> 这一份管**结构**，不管词句。
> 「AI 味」不是问题 —— AI 写的本来就偏严谨。问题是**观众会在第几秒划走**。
> 对照《文案创作法》一起用：那份管「怎么说」，这份管「先说哪句、后说哪句、哪句必须存在」。

---

## 一、规则从哪来（都是视频脚本类，不是语言润色）

| 来源 | 给了什么 |
|---|---|
| **banger-script-longform**（Jeff-Kazzee/bangers） | cold-open 无开场白 · 3~6 个 beat 每 beat 只教一件事 · **每 60~90 秒 re-hook** · payoff · 一句话收尾。原话：*"Leading with the key insight instead of an intro raises past-30s retention 15–20 pts"* |
| **youtube-script-writer**（raroque/boop-agent） | Hook 5 秒三模式（curiosity gap / bold claim / pattern interrupt）· Setup 5~20 秒 · **每 30~45 秒 re-hook** · **CTA 只能一个** · 交付前 retention checklist |
| **Retention-Engineered Script**（AgriciDaniel/claude-youtube） | Hook 拆成 **Grab(0-5s) / Promise(5-15s) / Stakes(15-30s)**，目标 30 秒处留存 >70% · pattern interrupt 每 60~90 秒 · 软 CTA 在 25% 处 · **标注 RETENTION RISK** |
| **explainer-videos**（omer-metin） | **90 秒规则：超过 90 秒留存掉 20%** · PAS（Problem-Agitate-Solution）· 视觉隐喻要「12 岁能懂」· 三步框架 |
| 中文侧（多篇脚本方法论） | 前 3 秒决定 80% 完播 · 钩子后必须有「价值铺垫」· 每要点 15~20 秒 · **中段是流失最高区** · 一条视频只讲一件事 · **结尾只放一个指令** · 自检三问 |

**其中最硬的一条**：explainer-videos 的 **90 秒规则**。我们定的 60~90 秒上限，正好和它撞上 —— 这不是巧合，是这类片子的留存拐点。

## 二、我们的结构骨架（70~90 秒版）

英文那几套是按 5~8 分钟设计的，我按比例压到了 90 秒：

| 段 | 时长 | 干什么 | 硬约束 |
|---|---|---|---|
| **① Grab** | 0~5 秒 | 最炸的那一帧。结果 / 冲突 / 反常断言 | **不许有任何招呼**（「你敢信吗」「你知道吗」「今天聊」全部禁止）。第一句就是结论本身 |
| **② Promise** | 5~15 秒 | 告诉观众「看完你会得到什么」，或者「这事跟你的关系」 | **必须有**。我们现在**整段缺失** |
| **③ Beat 1** | 15~35 秒 | 第一个信息块。**只教一件事** | 一个 beat 里塞两个概念 = 两个都没记住 |
| **④ Re-hook** | 35~45 秒 | 中段转折。「但这里有个问题」/「更奇怪的是」 | **必须有**。中段是流失最高区，不给新钩子就是等死 |
| **⑤ Beat 2** | 45~65 秒 | 第二层：机制 / 代价 / 反转 | 要接在 re-hook 后面，不能是平的 |
| **⑥ Payoff** | 65~78 秒 | 兑现 Promise。一句话能被人复述 | 不能新增信息，只能收 |
| **⑦ CTA** | 78~90 秒 | 一个动作 | **只能一个**。「艾特朋友」和「关注」同时出现就算两个 |

### 我们现在的骨架长什么样

```
00 钩子(2句) → 01~05 平铺内容(12~15句) → 06 落回观众 → 07 片尾(4句)
```

**缺 ② Promise**（观众不知道为什么该看下去）、**缺 ④ Re-hook**（中段 35~45 秒整段没有新钩子）。

这两刀是这轮要补的。

## 三、9 条可执行约束

### 结构类

**S1 · 第一句不许有招呼语。**
禁止：「你敢信吗」「你可能不信」「你知道吗」「今天我们来聊」「说个冷知识」。
理由：这些词占掉 5 秒里最贵的 2 秒，而且**不提供任何信息**。把后面那半句直接提上来。

**S2 · 8~15 秒内必须出现一句「承诺」。**
形态三种任一：
- 结果承诺：「看到最后你会发现，这条规矩是被骗出来的。」
- 关系承诺：「你手机里那张体检报告，用的就是这套逻辑。」
- 悬念承诺：「这中间少了一个人，而那个人是关键。」
判据：**把这一句单独拿出来，能不能回答「我为什么要看完」**。

**S3 · 中段（35~45 秒）必须有 re-hook。**
形态：「但这里有个问题」「更奇怪的是」「真正的麻烦在后面」。
判据：这一句必须**开一个新的信息口子**，不能只是过渡（「接下来我们看」不算）。

**S4 · 一条视频只讲一件事。**
写完自问：能不能一句话说出这条片在讲什么？说不出来就是塞多了。

**S5 · 一个 beat 只教一件事。**
不要在一个镜头里同时讲「机制 + 历史 + 应用」。三件事分三个 beat。

### 节奏类

**S6 · 每 15~20 秒要有一个「新东西」。**
新数字 / 新画面 / 新转折 / 新类比。90 秒的片，至少 5 个「新东西」。
我们现在的问题：01~05 段常常是同一类信息连续输出。

**S7 · 句长要有对撞。**
一句 ≤8 字紧跟一句 ≥18 字，念出来才有起伏。（`check_style.py` 已有此检查）

### 收尾类

**S8 · Payoff 不许是「总结」。**
「所以你看，X 就是 Y」是总结，不是 payoff。
Payoff 是**兑现开头那个承诺**：开头说「这条规矩是被骗出来的」，结尾就说「那 117 个油滴就是代价」。

**S9 · CTA 只能一个。**
「艾特你那个朋友」 + 「关注 脑脑不老佬」= 两个。观众只会执行零个。

## 四、自检清单（交付前逐条打勾）

```
□ 第一句是结论本身，不是招呼
□ 15 秒内出现了「承诺句」
□ 35~45 秒有 re-hook，且开了新口子
□ 全片能用一句话概括（= 只讲一件事）
□ 每个 beat 只有一件事
□ 至少有 5 个「新东西」（数字/画面/转折/类比）
□ 句长有对撞（≤8 字 + ≥18 字）
□ Payoff 兑现了开头的承诺，不是总结
□ CTA 只有 1 个
□ 整片 60~90 秒（>90 秒留存掉 20%）
```
