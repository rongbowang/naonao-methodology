# 谜题型选题与表现

> 2026-10-29 拆解抖音「小偏导」（原「相蕉线」，4 万粉 / 51.8 万赞 / 60+ 作品）。
> 素材：263 秒原片 + ASR 全文 + 逐帧抽图，都在 `参考/抖音/`。
> 结论先说：**他的技术门槛比我们低，赢在选题和结构的"留白"。**

---

## 一、他到底在卖什么

60 多条作品全是**数学谜题**，不是知识科普：

| 作品 | 谜题 | 背后的工具 |
|---|---|---|
| 蒙眼分 100 枚硬币 | 闭着眼把正面数分得一样多 | 互补守恒 |
| 两刀平分 100 颗乱珠 | 顺序再乱也能各分一半 | 项链分割定理 |
| 10 盒药只称一次 | 找出全部解药 | 二进制编码 |
| 12 颗球称三次 | 找出那颗不一样的 | 平衡三进制 |
| 九宫格拆弹 | 怎么按下最少的灯 | 矩阵求逆 |
| 四枚硬币 7 步必开门 | 蒙眼乱转也能同面 | 有限状态机 |
| 蚂蚁撞来撞去 | 为什么 100 秒内一定掉光 | 不变量 |

**知识科普**：我告诉你一个事实，你点头。
**谜题**：我给你一个条件，你**自己想答案**。

区别在观众的姿势：一个是"听"，一个是"想"。**视频开始的第一秒，他就已经参与进来了**——这是任何钩子技巧都换不来的留存。

## 二、选题：四条硬判据

一道题能不能拍，按顺序过四关，任一关不过就换题：

1. **规则能不能一句话讲完？**（≤15 秒，不许出现第二个"但是"）
2. **答案是不是一步？**（"把左边 10 枚翻过来"——一个动作。三步以上的，观众记不住也复述不出来）
3. **观众手边有没有东西能试？**（硬币、纸、火柴：有。天平、100 个抽屉：没有）
4. **答案能不能三句话转述给朋友？**（复述率 = 转发率。讲不清就是选题错了，不是文案不行）

第 3 条最容易被忽略，但它决定"看完会不会自己动手"。**自己动过手的题，才会被讲给别人听。**

对照我们的 NO.14（密立根扔数据）：规则要讲 40 秒，答案是一段历史，手边没东西可试，复述要说五分钟。四关全不过——**当时就不该拍**。

## 三、结构：前 37% 一秒钟解法都不给

他的 263 秒拆开是这样（这是全片最值钱的东西）：

| 时间 | 占比 | 干什么 |
|---|---|---|
| 0:00–0:19 | 7% | **把题装进生死场景**：密室、100 枚硬币、蒙眼戴手套、狱警下令 |
| 0:19–0:31 | 5% | **立靶**："胜率连一半都不到对吗？**当然不对了**" |
| 0:31–0:55 | 9% | **背书 + 加码**："华尔街量化机构压轴面试题" + "差一枚立刻处决" |
| 0:55–1:26 | **12%** | **★ 先证明"这根本做不到"**：算给他看，让人绝望 |
| 1:26–1:38 | 5% | 转折："数学家设计了 3 步降维"（**先报步数，给确定感**） |
| 1:38–2:00 | 8% | **指出直觉错在哪**："秘密藏在打破对半分的执念里" |
| 2:00–2:44 | 17% | 第 1、2 步 + 具体数字验算（假设 3 枚正面） |
| 2:44–3:22 | 15% | **换个数字再验一次**（假设 0 枚正面） |
| 3:22–3:34 | 5% | 抽成铁律 |
| 3:34–3:51 | 6% | 第 3 步：翻面 |
| 3:51–4:07 | 6% | 实战演示"3 正 7 反 → 7 正 3 反" |
| 4:07–4:19 | 5% | 收束 |

**三条可以直接抄的：**

**① 前 37% 不许解题。** 我们现在的片子是前 20% 讲完核心结论，剩下 80% 在解释。他是前 37% 全用来**让你想不通**。

**② 花 30 秒证明"不可能"。** 这是整条片子最反常识的操作——花 12% 的时长告诉观众"这题做不出来"。但没有这段绝望，后面的答案就没有重量。

**③ 答案给两遍，换数字。** 假设 3 枚正面算一遍，假设 0 枚再算一遍。**不是解释公式，是当场数给他看。**

## 四、画面：三种画材，一个状态机

全片 263 秒，只有三样东西：

| 画材 | 怎么画 | 干什么 |
|---|---|---|
| **硬币** | 双圆（外圈 + 偏移内圈）做出厚度 | 唯一主角 |
| **手**（手套） | 只画一只，从画面边缘伸进来 | 只做三个动作：抓 / 放 / 翻 |
| **角色 ∂** | 账号头像那个符号，圆头 + 两只细腿 | **只看不动**，当"观众" |

背景：浅米色渐变，一片空白。**没有边框、没有标题条、没有装饰**。

### 最关键的一招：把「正反面」变成可数的符号

- **正面** = 金色圆环 + 内部一竖
- **反面** = 白底 + 内部一横

不是靠文字标注"这是正面"，是**符号本身能数**。最后验证那帧，左边 7 个金点、右边第一排 7 个金点——**观众真的可以用手指头点着数**。

这是我最缺的一条：**我们的数字是打出来的（"117 条"），他的数字是数出来的。**

### 第二招：一个东西从头变到尾

纸/桌面/两个盒子，位置尺寸从头到尾不变。变的只有里面硬币的状态。

- 散乱错开的双圆 = 一把抓起来的（乱）
- 整齐排列的单圆 = 铺在桌上的（可数）
- 半透明高亮框 = "这一组"

**观众看的是"同一个东西在变"，不是"又换了一张图"。** 这和我们记忆里那条"一块分格道具从头用到尾，状态迁移=叙事推进"是同一件事。

## 五、我们和它的差距，一条一条对着看

| | 他 | 我们（NO.14~NO.20） |
|---|---|---|
| 选题 | 观众能自己想的题 | 一段历史 + 一个数据 |
| 第一秒 | 生死场景 + 一句话规则 | 一句结论 |
| 中段 | 先证明"不可能"（12%） | 直接讲机制 |
| 画面主角 | 一堆可以操作的对象 | 图表、数据、示意 |
| 数字 | 数出来的 | 打出来的 |
| 观众姿势 | 想 | 听 |
| 技术门槛 | 矩形 + 圆 + 一条路径 | 比它高 |

**"技术我们也能做"——对，而且更好做。** 他是手 K 动画，我们是代码生成，改一版重渲只要几分钟。真正缺的是选题和"敢留白"。

## 七、动手时踩到的四个坑（技术）

都是这次做样片时真撞上的，记下来免得下次再撞：

1. **`stroke-dasharray` 必须精确等于路径长度。**
   比它大 → 整条路径落在"实段"里，怎么调 offset 都是全显示；
   比它小 → 只能画出一截。估算的值（4600 / 7000）两种都错过，必须 `getTotalLength()`。

2. **虚线不能既当样式又当"逐段画出"。**
   已经是 `dasharray: 16 12` 的圆，再用 `dashoffset` 做生长，结果虚线一直完整显示。要生长就改半径。

3. **纸上的"洞"要有洞底。**
   只挖空 → 透出背景色 → 看起来像"纸上贴了个深色圆盘"。要加一层径向渐变（中心纯黑、边缘微亮）+ 一圈深色内描边，才读得出"有厚度的洞"。

4. **`K.txt()` 是 HTML div，塞进 `<svg>` 不显示。**
   svg 里要用 `<text>`。这次 21cm/45cm 一开始全丢，画面没报错。
