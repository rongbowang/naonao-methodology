# 视频怎么做得更生动 —— 方法

> 2026-10-29 用户：「动画的表现形式、文案的表现形式都要优化；选题也不够吸引人（比如 10-28 那期
> 117 个油滴就不够）；你去研究一下怎么写好这种文案。」
> 沿用「简笔画方法」的思路：**先把问题写成一句话，再去查、再去验。**

## 0. 把「不够生动」拆成三个能分别验证的问题

| 问题 | 验证手段 | 判据 |
|---|---|---|
| ① 每一秒，画面有没有在替台词干活？ | `_alive.py` / `_deadshot.py` | 最长静止 < 4s；镜头活动率 ≥ 35% |
| ② 每 10 秒，有没有一个新的信息缺口？ | 人工读稿（`_review.py` 只能查重复） | 每段结尾必须留下一个问题 |
| ③ 这个题材值不值得拍？ | 三闸评分（见第三节） | 违反强度 × 自我相关，任一项为 0 就是 0 |

## 一、动画：四种运动，只有一种在替内容干活

出处：Northeastern 信息设计专业对「运动在可视化里的四种角色」的分类
（*Motion Graphics That Actually Communicate*，Designer Daily 整理）：

1. **motion as data** —— 动的形状本身代表数据值
2. **motion as interpolation** —— 把离散的点连起来，让观众看到「状态之间是连着的」
3. **motion as storytelling** —— 引导注意力、转场、强调
4. **motion as captivator** —— 好看，但不承载信息

**我们的病：90% 的运动是第 4 类**（扫光、呼吸、缓动入场），内容是死的。

### 判据（一句话）
> **把声音关掉，只看画面，能不能说出这句话在讲什么？**
> 说不出来 = 这一段只有 captivator 运动。

### 三个可复用的做法

**① 让数据当演员**（最有效）
把台词里的数量变成**可数的图形**，让观众亲眼数一遍，而不是听你报数。

- 反例（旧 NO.14 `03_note`）：一个笔记本 + 三条灰条 + 三个红字淡入 → 活动率 18%，最长静止 7.2s
- 正例（新 `03_note`）：175 个点铺满画面，117 个被**一笔一笔划掉**（分三批咬住三句台词），
  计数器跟着从 0 划到 117，最后剩 58 个变金色 → 活动率 62%，最长静止 1.0s
  （演示片段 `工程文件/试验片/NO.14_03_note_新版演示.mp4`）

**② 一块道具的状态迁移**
同一个物件从头用到尾，只改状态（电量 100%→9%、纸从空到划满）。观众不需要重新认东西，
注意力全在「它变了多少」上。

**③ 一个概念锚点**
一镜只留一个视觉锚点，其余元素围绕它分布（*视觉叙事架构*）。
锚点动了，整镜就活了；锚点不动，加十个装饰也没用。

### 排版规矩（IBM 的字幕动效规范）
- 文字**从左到右、从上到下**出现，跟着阅读顺序
- 停留时间够读完（按 4.2 字/秒估）
- **绝不拉伸/压扁字形**（变形的字一眼假）
- 一个字都不许压在字幕安全区（底边 ≤1104）

## 二、文案：每 10 秒补一个「信息缺口」

出处：科普中国《5 个网感开关》+ Loewenstein 信息缺口理论。

### 结构（把长文拆成四拍）
```
钩子（0~5s）     一句反常识的话，不给答案
拆解（5~40s）    3~5 个模块，每块 ≤15s，每块结尾留一个问题
Wow Moment       最大的那个数字/反转，单独占一拍
落回观众         这跟你有什么关系 + 一句可迁移的判断
```
**上一段的结论必须成为下一段的问题**（这条以前就有，但经常没做到）。

### 五条硬规矩
1. **每个名词都要能画出来**。画不出来的（代价、隐情、体验、过程）全部换成具体物。
2. **删掉「一般来说 / 通常认为 / 研究表明」**，换成「谁、在哪、干了什么」这种可信单元。
3. **3-7-3**：开头 3 秒抛问题、中间 7 秒给一个对比案例、结尾 3 秒留一句行动暗示。
4. **不许用区间报数**（「几万年到十几万年」→「得走十几万年」），区间会把冲击力稀释掉。
5. **每个模块只讲一件事**，两件事就是两段。

### 「写得不够好」的具体症状（自查用）
- 读到第 3 句还没有画面感 → 缺场景
- 每句都对，连起来不知道在讲谁 → 缺主语（蹦豆子）
- 数字出现两次（钩子一次、正文一次）→ 悬念被提前泄掉
- 结尾是总结而不是提问 → 完播率断崖

## 三、选题：三闸评分（NO.14 就是死在这里）

| 闸 | 问题 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|---|
| **预期违反** | 说出来对方会不会「啊？」 | 我本来也不知道 | 有点意外 | 我原来信的是反的 |
| **自我相关** | 跟观众的身体/钱/每天做的事有关吗 | 没关系 | 间接 | 就是你自己 |
| **可视化** | 能不能一个画面说清 | 说不清 | 要想一下 | 一眼就懂 |

**总分 = 违反 × 相关**（乘法，任一项 0 总分就 0）。
可视化只用来决定「怎么拍」，不用来投票。

NO.14「密立根扔掉 117 个数据」为什么不行：
- 违反 = 1（观众对密立根没有既有预期，谈不上被推翻）
- 相关 = 0（一百年前的实验室账本，跟你没关系）
- **总分 0** —— 不是拍得不好，是选的时候就不该选。

对照：NO.15「39 人拿同一份报告都说准」违反 2 × 相关 2 = **4**（你被测试过）；
NO.17「树懒为拉一次屎赌命」违反 2 × 相关 2 = **4**（拉屎是身体经验）；
NO.39「婴儿 300 块骨头，成人 206」违反 2 × 相关 2 = **4**（就在你身上）。

## 四、每期开拍前的检查表

```
[ ] 选题三闸算过分（≥2 才开）
[ ] 钩子能单独念，够炸，且不等于片名
[ ] 每段结尾留了问题
[ ] 每一镜有一个「数据当演员」或「道具状态迁移」的动作
[ ] 关掉声音能看懂每个镜头在讲什么
[ ] _alive 最长静止 < 4s、每镜活动率 ≥ 35%
```
