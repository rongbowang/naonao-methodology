# 简笔画怎么画才像 —— 方法

> 2026-10-28 用户：「不能单单只依靠你的想象来画……你在画之前先形成一个问题，
> 怎么画好一个树懒的简笔画，然后你再去深究这个问题。」

## 0. 病根：凭想象画，画的是「我记得的样子」

同一个树懒，我画了两版，都不像：

| 版本 | 画了什么 | 错在哪 |
|---|---|---|
| 旧版 `sloth` | 圆头 + 两只立起来的「耳朵」+ 圆环眼 + 笑脸 + 椭圆身体 | 树懒**没有外露耳廓**；眼睛不是圆环；笑脸是卡通表情不是解剖结构 → 读成外星小怪 |
| 新版 `sloth2`（WIP） | 树枝 + 两只细胳膊 + 大圆头 + 两道「胡须」+ 分离的椭圆身体 | 身体和头断开读成两块；钩爪画成小蚯蚓；眼纹画成胡须 → 读成猴子 |

结论：**没有参照物，我画的永远是"我脑子里的平均图形"，不是这个动物。** 对比图见 `_webtmpl/_art_cmp.png`。

## 1. 画之前先立三问（不回答完不许动笔）

1. **这个物的三个识别特征是什么？**（其余全部可以省）
2. **它靠什么姿态被一眼认出？**
3. **缩到指甲盖大小，先看见的是哪一个？**

以树懒为例：
- 三特征 = ① 三枚长钩爪 ② 浅色面罩 + 两道斜向深色眼纹 ③ 倒挂
- 姿态 = 四肢上钩、身体下垂成 U/水滴
- 缩略必见 = 钩爪（其余都可以弱化）

> 这三问答不出来 = 还没看懂这个东西，先去查，别画。

## 2. 找参照（这一步不许跳过）

| 要什么 | 去哪 | 许可 |
|---|---|---|
| 真实照片（起形、对比例） | Wikimedia Commons、Openverse | 优先 **PD / CC0**，CC-BY 要记署名 |
| 现成矢量（角色、图标） | openclipart（CC0）、OpenMoji（CC BY-SA 4.0）、Material Symbols（Apache-2.0） | 记清楚 |
| 同类优秀简笔画（学画法，不抄） | 参考片、绘本、图标集 | 只学结构不描线 |

落地规范：存 `工程文件/参考/简笔画/`，命名 `ref_<主体>_<来源>.jpg`，
同目录建 `出处.md` 记一行（谁、哪来的、什么许可）。

## 3. 三条落地路线（按对象选，不要混用）

### A 矢量描摹（适合实物：茶壶、列车、猫、水柱）
1. 照片去背（主体抠出来，背景纯白）
2. 转二值 / 边缘
3. 自动描边成贝塞尔（potrace / vtracer）
4. **简化**：曲线容差拉到轮廓只剩 20~40 个锚点，线宽统一 3/100
5. 手工补三个识别特征（自动描摹一定会丢小结构）

### B 素材改制（适合角色 / 图标：树懒、人、动物脸）
1. 取 CC0 矢量（openclipart 等），**不要**照片
2. 拆掉填充色，只留外轮廓
3. 统一线宽、圆头圆角、单色 currentColor
4. 与品牌包对齐（viewBox 100×100 / stroke 3）

### C 照片双色调（适合封面大图、氛围图）
1. 转灰度 + 提对比
2. 双色渐变映射（我们的组合：`#050C16 → #FFD166`，或 `#FFE7B0 → #7A1F1F`）
3. 抠主体、压暗角
4. 质感最好，但需要抠图工具

**已验证**：`参考/简笔画/dt_gold.png`（PD 照片做的金色双色调）比任何一版手绘简笔画都有质感。

## 4. 三关验收（过不了就重画）

1. **叠图**：SVG 叠在照片上，看关键轮廓是否咬合（工具 `_webtmpl/_art_cmp.html` + `_cmp.mjs`）
2. **缩略图**：缩到 32px 看，还认得出是什么
3. **盲测**：把图单独发给一个不看上下文的人，问「这是什么」

## 5. 工具缺口（要装得先问）

| 已有 | 缺 |
|---|---|
| PIL / numpy / scipy、Chrome + puppeteer（可叠图、可截图） | **描摹器**：`potracer`（纯 Python，无需编译）<br>**抠图**：`rembg` 或 `opencv-python`（Canny + 轮廓） |

装上这两个，路线 A 和 C 就能自动跑；不装就只能靠"看照片手描"，容易退回凭想象。

## 6. 这套方法对视频里的手绘同样适用

`scenes.js` 里的人物、动物、道具也是我手写的路径，同一个病根。
区别只是那边的验收标准是多一条 `_alive` + `_gcheck`。
以后画之前同样先立三问 + 找参照。
