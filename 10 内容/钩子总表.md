## 一、钩子的四个层级（第二次退稿的根因）

用户第二次退稿的原话：

> 「我一直觉得你的故事写得不够那种让人特别想看的感觉。比如说，就这个电池和青蛙腿的事情，
>
> 你可以这样写：你说，你敢相信吗？你骑的电动车能跑居然是因为一只青蛙。
>
> **就是这种很离谱的，越离谱越好。**&#x4F46;是你最后真的能够深究起来的话，
>
> 那电动车能跑那就是有电池，有电池那电池怎么来的？就是因为青蛙腿，是不是？
>
> 这样就让人一看就觉得想看下去。」

这句话把钩子分成了四个层级，我前三版一直卡在 L1：

| 层级             | 写法                      | 观众的真实反应        | 结论             |
| -------------- | ----------------------- | -------------- | -------------- |
| **L0 前提句**     | 「两台老虎机，单玩都输」            | 哦。（划走）         | 废              |
| **L1 现象描写**    | 「一条死了半天的青蛙腿，刀尖一碰，居然还会弹」 | 哦，有点意思。        | **这是我现在写的，不够** |
| **L2 跨域因果**    | 「你骑的电动车能跑，居然是因为一只青蛙」    | 胡说！…等一下，好像是真的？ | **用户要的**       |
| **L3 跨域 + 在场** | 「你昨晚充的那格电，源头是一只青蛙的腿」    | 同上，且更强（时间更近）   | 进阶目标           |

**L1 和 L2 差在哪：**

- L1 只是把**同一件事**描述得生动一点，观众是旁观者，没有反驳冲动。
- L2 把一个**完全不相干、观众每天都在用的东西**，硬接到核心事实上，先制造"这不可能"，再揭穿"但这是真的"。
- **观众的反应链条是：胡说 → 等等 → 好像真是这样 → 我得看完。** 这个"反驳冲动"才是钩子。

**唯一红线：中间那条因果链必须是真的。** 这是 L2 和标题党的分界线。跳一步就是骗人，跳四步才叫离谱。

## 二、L2 钩子的写法（可执行）

### 模板

```
你敢信吗？<你每天都在用的东西> + <它正常的功能> + 居然 + 因为 <一个完全不搭的东西>
```

### 三要素（缺一不可）

| 要素       | 要求                                           | 反例                    |
| -------- | -------------------------------------------- | --------------------- |
| **① 在场** | 一端必须是观众**今天就用过/见过**的东西：电动车、洗碗、地铁、泡茶、日历、医院的病历 | 「一台伽伐尼电堆」——没人用过       |
| **② 荒诞** | 另一端必须反差极大（生物 / 尸体 / 小动物 / 一张纸条），跨的领域越远越好     | 「一块电池」——跟电动车同一域，不荒诞   |
| **③ 真链** | 中间每一环都可查，**不能跳步**                            | 「手机指纹解锁靠泡水」——这是硬凑，链断了 |

### 怎么找那条链（四步）

1. 写下本期核心事实（爆点一句话）。
2. 问：**这个事实最后影响到了现代人哪个每天都在用的东西？**（越现代、越日常越好）
3. 从那个东西**倒推**回核心事实，每一环都要能查证。
4. 数一数跨了几环、跨了多少年——**跨得越远越炸**。

现成的例子：

```
青蛙腿 →（抽搐）→ 动物电 →（伏打反驳）→ 伏打电堆 → 电池 → 你的电动车
   ↑ 4 环，跨 200 多年，一端是尸体，一端是车 —— 这就是 L2
```

```
茶叶 →（倒水）→ 表面张力被拉出梯度 → 茶叶逆流 → 管道里下游能污染上游
   ↑ 3 环，一端是杯底，一端是自来水 —— 也能成立
```

### 开场白可以变，结构不能变

- 「你敢信吗？」
- 「你敢相信吗？」
- 「我说个事你别不信——」
- 「你猜怎么着？」（慎用，偏轻佻）

**别每期用一模一样的四个字**，6 期连用会变成新模板。至少两种轮换。

## 五、片尾固定格式

**四句：恭喜 → 过渡 → 钩子 → 关注**（2026-10-21 用户定：抛下期钩子前必须先有转折，否则观众不知道这是预告，会觉得突兀）

```
1. 恭喜你，第 N 个知识装进脑子了。
2. 下一期我们来看。
3. 你敢信吗？<L2 跨域钩子>
4. 关注 脑脑不老佬，明天继续涨脑子。
```

- 「第 N 个」后面**必须有宾语**（知识），悬空 → `check_style.py` 直接 FAIL。
- **第 2 句是过渡，不是钩子**：它只干一件事——告诉观众"接下来这句是下期预告"。
  固定用「下一期我们来看。」，单独成句、单独占一行，**不许合并进钩子**（合并会变成"下一期我们来看你敢信吗"这种绕口的长句）。
- `check_style.py` 会把这类整句剔出去（正则 `^下一期…来看`），**不计入钩子 18~30 字 / 6 秒预算**。
- ~~不加"下一期"前缀~~ —— 2026-10-21 作废：没有这句转折，钩子从"恭喜"直接跳"你敢信吗"太突兀。

## 六、事实核查：金星「一天比一年长」

**结论：成立，但要说清是"自转一圈"。**

| 项                 | 数值             | 来源                    |
| ----------------- | -------------- | --------------------- |
| 自转周期（恒星日，转一圈）     | **243 个地球日**   | NASA Venus Fact Sheet |
| 公转周期（一年）          | **224.7 个地球日** | 同上                    |
| 一个完整昼夜（太阳日，日出到日出） | **约 117 个地球日** | 逆行自转抵消掉一半             |

- ✅ 「自转一圈 243 天 > 公转一圈 225 天」成立。
- ⚠️ 不能笼统说「金星上一天 243 天」——观众若理解成"日出到日出"是 117 天。
- ⚠️ 不能说「一年比一天长」（反了）。
- ⚠️ 「每天都能过新年」不准确：一年里只能看到约 2 次日出。

已落进 `v8_venus/script.py` 的写法：

```
金星上的一天，比它的一年还长。
你在那儿过一个白天，它已经绕着太阳跑完一整年了。
```
