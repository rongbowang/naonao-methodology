## 0. 三十秒读懂

**这是什么**：数理推理类短视频账号「脑脑不老佬」的生产线。一天一期，竖屏 1080×1440 / 30fps。
一期 = 一道谜题（约瑟夫环、希尔伯特旅馆、蒙提霍尔…），2~4 分钟，用「你被关进这个局面里」的视角讲完。

**画面怎么来的**：不是剪辑，不是文生视频。每期是一个网页（`web/index.html` + `web/js/scenes.js`），
所有画面用 SVG + CSS + 原生 JS 写死，`update(ctx, t, shot)` 是 t 的**纯函数**（无状态、无 rAF）。
然后用 puppeteer 开 Chrome，逐帧 `window.__seek(t)` + 截图，再 ffmpeg 拼成 mp4。
好处是每个像素都精确、改一个动作只改一行代码；坏处是**每句台词都要自己设计一组动作**，工具省不掉这部分。

**配音**：MiniMax 付费 TTS（`Chinese_radio_host_male_vv1` 深夜电台，语速 1.16），
按句合成再拼，时间码取 `timestamped_words[]` 的绝对字符位置归行。

### ③ 写 `script.py`

台词唯一真源。结构：

```python
TITLE = "围一圈报数"
SUBTITLE = "约瑟夫环"
BAODIAN = "报到 3 就出局，活下来的是 14 号"    # 一句能说出口的爆点
SHOTS = [
  {"id": "00_hook", "scene": "hook", "lines": [
      {"t": "二十五个人，最后只活一个。", "sfx": [{"t": 0.3, "name": "bass-rumble-short", "vol": 0.3}]},
      ...
  ]},
  ...  # 7~11 镜
]
```

**文案三条硬规则**（违反必退稿，跑 `check_style.py` 会自动查）：
- **禁第一人称感受**（「我愣住了」这种）：冲击力只由数字对撞、画面、把观众卷进来（你）承担。
  阈值：全片「你」≥5 次、「我/我们」只允许「泛指共识」和「转述研究结论」两种用法。
- **禁第一人称实验背书**（「我们真跑了一遍」）：**让结果当主语**。
- **正文讲成故事，不要蹦豆子**：每句回答「谁 + 做了什么 + 结果」，句间用口语承接词
  （可他 / 结果 / 于是 / 最后 / 反倒）；数据只在故事需要它的位置出现。
  **上一段的结论就是下一段的问题。** 机器信号：连续 6 句落在 5~10 字 = 匀速 FAIL。

规格：旁白 430~650 字（硬上限 680），镜头 7~11 个。

### ④ 文案自检

```bash
$PY "02 工具/check_style.py" "30 制作/2026-11-11_xxx/script.py"     # EXIT=0 才许进 TTS
$PY "02 工具/_review.py" "30 制作/2026-11-11_xxx/script.py"          # 查结构：同一件事讲两遍
```

`check_style` 查**句子怎么写**，`_review` 查**结构**（单句都合格、但一个意思讲了两遍，只有它抓得到）。
`_review` 五条：① 同一动作跨镜重复 FAIL ② 视角词 ≥3 FAIL ③ 句间 2-gram Jaccard ≥0.80 FAIL
④ 首尾复读 ≥0.22 FAIL ⑤ 接缝重复 ≥0.30 WARN。**改法不是换说法，是换问题。**

### ⑤ 写 `06_画面绘制.md`（★ 动手画之前必须写完）

按 `01 操作手册/画面绘制规范.md` 第四版，**每镜 19 项**：
镜号时段 / 景别 / 视角机位 / 焦点主体 / 构图 / 四层画面构成（背景·中景·人物·氛围）/ 光影 /
色彩基调 / 元素清单 / 角色表演 / **逐句动作表** / 运镜 / 转场 / 音效提示 / 文字字卡 /
连续性 / 出画入画 / 颜色清单 / 状态。外加每镜一条生图 prompt（以 `no text` 收尾）。

两条否决线：
- **不许用色点/色块代替人**。人形硬指标：头 R / 肩宽 = 1.55×头径 / 身 2.2R / **手 = 实心圆** / 腿脚 / 地平线。

### ⑧ 写 `web/js/scenes.js`（★ 一期一个文件，主要工作量在这）

```js
"use strict";
const { W, cam, gpop, svgFade, win, define, stage2, glow, sfx, outroStd } = window.LIB;
const { islander, silhouette, vignette, grain } = window.ASSET;

define("hook", (box, shot) => {
  const svg = stage2(box, "bghk", "#081020", "#050C16");
  const body = islander(svg, { h: 360, x: 540, y: 1020, cloth: "A", mood: "grave" });
  // ...建元素，全部 opacity:0
  return { svg, body, _cam: [{ t: 0, s: 1.05 }] };
}, (ctx, tl, shot) => {
  const L = (i) => shot.lines[i].g0 - shot.start;   // ★ 时间锚一律从 timeline 读，零硬编码
  const q = OUT(seg(tl, L(0), L(0) + 0.6));
  ctx.body.g.setAttribute("opacity", q.toFixed(3));
});
```

**五个必须遵守的写法**
1. `update(ctx, tl, shot)` 必须是 `tl` 的**纯函数**。每个分支都要把 opacity 算出来，
   否则 seek 直接跳到某一帧时元素不显形（踩过一次：照镜子的人直跳帧变透明）。
2. 时间锚用 `L(i) = shot.lines[i].g0 - shot.start`，不写死秒数。
3. `build` 和 `update` 是**两个独立作用域**。`CX/CY/EY` 这类共用常量必须提到模块顶层。
4. `W(shot, i, "词")` 匹配不到会**静默失效**（返回 0），改台词后必跑 `_wcheck.py`。
5. **引擎画字是必须的**：编号 / 算式 / 字卡一律用 `K.sp(svg, "text", ...)` 或 `K.chip()` 叠上去。
   「模型不许写字」说的是生图 prompt 以 `no text` 收尾，不是画面不能有数字。
   （这一条被误解过两轮：把 25 个编号画成空心金圈、把算式整个省掉。）

**禁用的写法**
- `K.txt()` 是 HTML div，塞进 `<svg>` 不显示且不报错。
- camera 平移上限 `(1-1/s)/2×1080`，s=1.10 时最多 49px，超了露白边。
- 画面文字底边 ≤ 1104；开 camera 放大后只排到 ≤ 990。

## 4. 音效四段链（缺一段就静默失效）

```
script.py 镜级 sfx:[{t|line+at, name, vol}]
  → gen_timeline.py 摊到 timeline.json 每句 lines[i].sfx
  → scenes.js build 里 LIB.sfx(box, s.t, s.name, s.vol)
  → engine.__collectSFX() 转全局秒
  → capture.mjs 写 sfx.json
  → mux.py 第三轨
```

音量口径：`vol = 10^((目标LUFS + 19)/20)`，实际响度 = −19 + 20·log10(vol)；
要垫在旁白（−20 LUFS）下方 −12~−16 dB。短音效（<0.5s）用 gated loudnorm 测不出，
重复拼 8 次再量。

`mux.py` 常量别改：`USE_DUCK=0` / `VOICE_I=-20.0` / `VOICE_LIMIT=-3.0` / `BGM_UNDER=10.0` / `TARGET_I=-18.5`。

## 5. 踩过的坑（照抄别再踩）

### 渲染类
1. **`_seg` 断点续跑陷阱**：改画面后不挪走旧段，合出的是旧画面。挪到 `99 归档/_旧段_<日期>/`。
2. **`capture.mjs --worker` 只能串行**（8130 端口），并行会假成功。
3. `_seg/list.txt` 必须写**相对文件名**，绝对 UNC 路径会拼出 `_seg/_seg/...`。
4. 拼完必须 `ffprobe` 核帧数，不符就中止，别让 mux 拿旧帧合。

### 人物绘制类
5. **子 Agent 最爱干的事是把 `islander` 的双手藏掉**（`P.handL.setAttribute("opacity",0)`）。
   人立刻变成「圆头 + 圆角矩形」的方块，剪刀悬空、蒙眼摸硬币没有手。
   **只有角色是纯剪影时才能藏**。
6. `islander` 的手默认挂在躯干下缘（`armY + 0.40H×0.52`），像两个球黏在衣角；
   要抬到躯干中部改成 `×0.28`。
7. 人物站在「俯视桌面」的场景里时，站姿的腿会和桌面透视打架 → 藏腿脚改半身像，
   躯干下缘贴桌沿。
8. 圆形排布按参数 t 等分 → 长轴两端弧长偏大，左右挤成一团。**必须按弧长等分**。
9. 编号统一向上偏移会撞头；改成沿「圆心→人物」的**径向**外推。

## 9. 横屏 4:3（2026-11-02 起，NO.19 及以后）

**规格**：1440×1080 / 30fps。竖屏 1080×1440 的那一套**没有废**，两套并存 ——
尺寸的唯一来源是 `web/size.json`，`gen_timeline.py` 把它写进 `timeline.json` 的 width/height，
引擎（kit/lib/assets/engine）与所有体检脚本都从那里读。**不要再在任何地方写死 1080 / 1440。**

```bash
python "02 工具/_canvas.py" NO.24           # 该期切横屏（幂等，可重复跑）
python "02 工具/_canvas.py" --all           # 五期一起
python "02 工具/_canvas.py" NO.24 --w 1080 --h 1440   # 切回竖屏
```

`_canvas.py` 干的事：写 size.json → 注入 `K.VW / K.VH / K.CX / K.CY / K.SAFE_BOT` →
把 lib.js 的全屏层/光斑/片尾、assets.js 的 grain/vignette、engine.js 的舞台与字幕、
capture/_check/_gcheck/_overlap/_shot 的 viewport 与越界阈值，全部改成读画布尺寸。

**横屏后必须重排，不能缩**。竖着少 360px、横着多 360px，等比缩只会让人更小。
本期定下的构图语法（NO.22 / NO.23 已按这个做完）：

- 桌子铺满下半幅，桌沿 y≈600~660；图纸、硬币、道具全摊在桌面上
- 人站桌后、靠右（x 940~1010），h 480~540 —— 头径 175~196，比竖屏的 138 大 27%~42%
- 道具区 x 120~1010，与人分栏
- 画面元素底边 ≤ 800（横屏 `K.SAFE_BOT = 760`；字幕顶边 ≈ 805，字号 46、bottom 84）

**四条画面铁律（都踩过）**

1. **build 顺序：人 → 桌子 → 道具**。桌沿以下被桌面挡住，腿自然藏好；
   先建桌子再建人，人的躯干底边会悬在桌沿上方一百多像素，像浮在桌上。
2. **手臂要从肩膀长出来**（两段线 + 肘点），不能是「一个手掌 + 68px 短袖」——
   人在右侧时那只手会孤零零悬在画面中央。
3. **islander 的几何量是「以脚底为原点」的局部坐标**，算肩点要加 `baseX / baseY`，
   漏了 baseY 手臂会从画面顶上冒出来。
4. **只让一条手臂做动作**（朝向道具那一侧），另一条垂手；两条同时伸到身前会交叉成 X。
   只有「抱头」「托举」这类对称动作才两只手一起。

**片尾 `outroStd` 已自适应**：横屏走左右两栏（脑子在左、徽章与胶囊在右），竖屏还是上下居中。

**已知可接受的体检告警**（别当 bug）：道具「有意飞出画外」（NO.22 的中块/左块）、
标尺从画外滑入（NO.22 的 `no` 镜），这两种 `_check` 会报越界，是设计。

**一个把自己坑了半小时的低级错**：改一堆 `glow(svg, "id", 色, x, y, r, peak)` 时用正则批量替换，
把第 6 个参数（peak，0~1 的强度）写成了半径 → 整片变成一块块实心色斑。
**批量改正则之后必须拿一帧出来看**，光靠 `_check`（它只量越界）发现不了。
