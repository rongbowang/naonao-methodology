# 用你自己的声音：三种做法 + 具体操作

> 2026-10-31 定。目标：把「AI 播音腔」换成「你的声音」。
> 前提：本机有专业录音设备，但白天更常用手机。**手机在安静小空间里，往往比电容麦在没吸音的房间更干净。**

---

## 三种做法，先看区别

| 做法 | 每期要你花的时间 | 效果（像真人） | 适合什么时候 |
|---|---|---|---|
| **A 直录 + 修音** | 每期 8~15 分钟 | **95** | 想一次到位，且你愿意每期开口 |
| **B 克隆音色，AI 念稿** | 一次性 5 分钟，之后 0 | 85~88 | 想彻底不开口，量产优先 |
| **C 混合（推荐）** | 每期 5~8 分钟 | **93** | 关键段落你录，过渡段落用克隆 |

### 为什么推荐 C
- 钩子、那个「他没死」的瞬间、结尾三句 —— 这几处必须是你**真说**的，AI 念不出那个停顿。
- 中间的推理过渡段，克隆音色完全够用，省一半时间。
- 观众听到的一直是同一个声音，感觉不到切换。

### 克隆这条路的两条硬规矩
1. **必须本人实名**：MiniMax / Fish 都要求授权声明，不能克隆别人的声音。
2. **素材要覆盖不同语气**：全是陈述句，克隆出来的声音只会念陈述句。

## 一、手机怎么录（这一步决定 70% 的成品质量）

### 环境
1. **找最小的空间**：衣柜（挂满衣服）最佳，其次是被子堆、床帐里。空间越小，混响越少。
2. 关空调、关风扇、关窗、拔掉冰箱附近的插排。
3. **先录 10 秒纯静音**，用来给我做底噪样本。

### 姿势
- 手机离嘴 **15~20 厘米**，稍微偏一点（不要正对，避免喷麦的"噗"声）。
- 手机竖着放，**别用手拿着**（手会传震动），垫在衣服上或架起来。
- 用**系统自带录音机**。微信语音、QQ 语音都会压缩，不要用。

### 怎么念
1. **每句之间停 1~1.5 秒**——我要靠这个停顿切句，不然得靠猜。
2. 念错就**整句重念**，不要接半句。
3. 语速比你感觉"正常"的慢 20%。你以为的慢，录出来才是正常。
4. **不要"朗读"**。想象你在跟一个人讲一件刚发生的事，不是念课文。
5. 开头先随便念两句暖嗓，不录进正式素材。

## 二、克隆素材清单（3~5 分钟，照着念）

> 直接拿《NO.17 文案_v3_遗书体.md》念一遍就够，但**必须补下面这几类**，
> 否则克隆出来的声音只会一种语气。

| 类型 | 念什么 | 为什么 |
|---|---|---|
| 陈述（大量） | 稿子正文 | 主体音色 |
| 疑问 | 「那句话还能指谁？」「那要是有两个呢。」 | 克隆要学到升调 |
| 极短句 | 「别找了。」「废话。」「他没死。」 | 短句的重音位置 |
| 长句 | 「你看得见岛上每一个人的眼睛，却偏偏看不见自己那一双。」 | 换气位置 |
| 数字 | 「九十九个人」「一百天」「三个月前」 | 数字读法（很多人在这里露馅） |
| 情绪 | 郑重：「就这一层，值一百条命。」 | 落点语气 |
| 日常口语（30 秒） | 随便说：今天吃了什么、这事你怎么看 | **最关键**——让模型学到你的自然节奏 |

**总时长 3~5 分钟最佳**（10 秒也能克隆，但情绪只有一个档）。

## 三、录音怎么修（三条命令，不用耳朵猜）

拿到 `xxx.m4a` 之后：

```bash
# 1) 转 wav 48k（克隆平台都吃这个）
ffmpeg -i 录音.m4a -ar 48000 -ac 1 -c:a pcm_s16le 干净.wav

# 2) 去底噪 + 轻压缩（把气口和口水音压平）
ffmpeg -i 干净.wav -af "highpass=f=90,afftdn=nf=-25,acompressor=threshold=-20dB:ratio=3:attack=8:release=200" 修过.wav

# 3) 响度归到 -16 LUFS（短视频标准，比成片的 -18.5 略高，留混音余量）
ffmpeg -i 修过.wav -af "loudnorm=I=-16:TP=-1.5:LRA=11" 交付.wav
```

**或者更省事**：把原始录音丢到 `podcast.adobe.com/enhance`（免费、免注册），
它的一次性去混响能力强过我上面三条命令，尤其适合手机在房间里录的。

## 五、落地顺序（建议这么走）

1. **今天**：你手机录 3 句（就用下面这三句），发我 → 我做三种后期给你听，判断"你自己录的效果行不行"。
2. **行**：录 3~5 分钟完整素材 → 克隆 → 出第一条用自己的声音的片子。
3. **不行**（比如口音重、气不够）：退回方案 A，我帮你把后期做到能听；或者上专业设备 + 吸音。
