## 二、MiniMax（先开这家，最快）

### 步骤
1. 打开 **https://platform.minimaxi.com**，手机号注册
   - 注意域名是 `minimaxi.com`（国内站），不是 `minimax.io`（国际站，账号和计费完全独立）
2. **实名认证**：「账户管理 → 实名认证」，个人认证即可。**不实名创建不了密钥**
3. **拿 API Key**：「账户管理 → 接口密钥」→ 创建新的密钥
   - ⚠ **密钥只在创建时完整显示一次**，关掉弹窗就只剩掩码，必须当场复制
4. **拿 GroupId**：「账户管理 → 基本信息」，是一串数字
5. 把两样发我：`API Key`（`sk-` 开头）+ `GroupId`

### 填进配置
`02 工具/_tts_key.json`：
```json
"minimax": {
  "api_key": "sk-xxxxxxxx",
  "group_id": "1234567890",
  "model": "speech-2.8-hd",
  "voice_id": "male-qn-qingse",
  "speed": 1.08
}
```

## 三、豆包（音色更像抖音，但要开的服务多）

### 步骤
1. 打开 **https://console.volcengine.com**，注册 + **个人实名认证**
2. 「语音技术控制台」→ **创建应用**
3. 左侧「API 服务中心 → 音频生成大模型 → **语音合成大模型**」→ 开通
   - ⚠ **开通后要等 5~10 分钟生效**，页面上能看到「音色列表」才算成功
4. **拿 API Key**：控制台 → 「API Key 管理」→ 创建（新版控制台只要 API Key，不用 AppID/Token）
5. **拿 Speaker ID**：控制台 → 「音色库 → 探索」→ 挑一个音色 → 右侧**复制音色 ID**
   - 形如 `zh_male_xxx_moon_bigtts`，克隆音色是 `S_` 开头
6. 把 `API Key` + `Speaker ID` 发我

### 填进配置
```json
"doubao": {
  "api_key": "你的key",
  "speaker": "zh_male_beijingxiaoye_moon_bigtts",
  "resource_id": "seed-tts-2.0",
  "speech_rate": 8
}
```

## 五、技术要点（我这边已经处理掉的坑）

### 时间码是硬门槛
字幕全靠句级时间码。没有它，整条字幕会错位。
- **MiniMax**：`subtitle_enable=true` + `subtitle_type=sentence`，返回 `data.subtitle_file`（一个 JSON 下载链接，**毫秒时间戳、句级、每句 ≤50 字**）
  - ⚠ 链接会过期，代码里合成完立刻下载
- **豆包**：`enable_subtitle` 走 WebSocket；HTTP 接口直接返回 `sentence.words[]` **字级**时间戳（秒），我按标点把字拼成句

### 兜底链路
拿不到时间码不会炸 —— 自动退回 `tts_whole.py` 里原有的「静音检测 + DP 匹配」，字幕仍然能出，只是精度低一档。

### 与旧管线的兼容
`tts_whole.py` 加了 `--engine edge|minimax|doubao`，输出格式完全不变，下游 `gen_timeline` / `build_voice` / `mux` 一行都不用改。

### 已探活验证
用假 key 打过两家服务器，返回的都是「key 无效」：
- MiniMax `1004 login fail`
- 豆包 `401 Invalid X-Api-Key`

说明 URL、请求头、body 结构都是对的，**只差真 key**。
