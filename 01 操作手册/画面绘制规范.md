# 画面绘制规范（第四版 · 超详细分镜版）

> 位置：**剧本定稿之后、配音之前**。没签收，不许配音；没签收，不许开画。

## 一、画幅与渲染基准（先写死，所有坐标都基于它）

| 项 | 值 |
|---|---|
| 画幅 | 竖屏 1080 × 1440 像素 |
| 帧率 | 30fps |
| 坐标原点 | 左上角 (0,0)，右下角 (1080,1440) |
| 字幕安全区 | 文字底边 ≤ 1104；该镜有 camera 时只排到 ≤ 990 |
| 出画判定 | 元素任何部分 < 0 或 > 1080/1440 即算出画（体检工具会查） |
| 画布中心 | (540, 720) |

所有元素坐标、尺寸、色值都必须写**具体数值**，禁止写"中间""旁边""适当"这类词。

## 二、两条否决线（违反任一条，整份文档退回重写）

### 1. 不许用「颜色点」代替人

- 画面里只要出现「人」这个概念（岛民、守卫、住客、老板、叙述者、会议室里的一圈人），就必须画成**人形**：头 + 肩 + 身。
- 不许用圆点、方点、色块、图标代表一个人。编号可以叠在人头顶，但人本身要画出来。
- 「两百个人」不许画两百个点：画 ≤50 个真人形（四排分层，见 §五），用「外围淡剪影延伸到画外」暗示数量。

**人形画法（照抄，别自己发明）**

| 部位 | 画法 | 关键 |
|---|---|---|
| 头 | 圆，半径 R | R 全片统一（建议 R=26） |
| 肩 | **宽 = 1.55 × 头直径** | ★ 低于 1.4 会被读成钉子 |
| 身 | 从肩往下收的梯形/圆角矩形，高约 2.2R | 站姿必须落地 |
| 手 | **实心圆**，半径 0.42R，挂肩两侧 | 抬手/挥手/指点靠这个圆位移 |
| 腿 | 两条短竖线，或一个裙摆三角 | 走动用左右摆 |
| 地平线 | **必须有**，一条横线，人站在线上 | 没有地平线人就是飘着的 |

**眼睛（本系列核心戏）**：两只小实心圆画在头上，颜色 = 红 `#E23B3B` / 蓝 `#2F6FD0`。主角自己是**空心眼**（描边不填），表示他看不见自己的颜色——全片唯一允许的「空」元素。

### 2. 每一句话都要有动作

- 必须给**逐句动作表**：这一镜几句就几行动作，一句不许空。
- 动作必须命中下面任一条，否则算「静止」：
  - **大块位移**：人走动、转身、抬手、倒下、门开、物体滑移
  - **大块变化**：换色块、换构图、换在场人数
  - **进出场**：新元素进入 / 旧元素离场
- 不算动作的：透明度淡入、1.02 倍呼吸、细线移动、小圆点闪烁、纯文字浮现。
- 一镜超过 12 秒：逐句动作里至少 2 处「整屏级」变化（换背景块 / 换构图 / 主体换位）。

## 三、每镜必写项——19 项分镜要素（缺一项 = 没写完）

> 每镜一个分节，按下面 19 项顺序写。每一项给具体数值/方向，禁止含糊词。

### 1. 镜号与时段
`NO.xx_00_hook`　起止秒（如 `0.15–6.07`）　几句　总时长

### 2. 景别（九级选一，写明）
| 景别 | 画面内容 |
|---|---|
| 大远景 | 主体极小，环境为主（俯瞰全岛） |
| 远景 | 人占画面高度 ~1/4（码头+人+海） |
| 全景 | 人全身占 1/2~2/3，脚落地 |
| 中景 | 膝盖以上 |
| 中近景 | 腰以上 |
| 近景 | 胸以上，表情清晰 |
| 特写 | 头/道具占画面大部分 |
| 大特写 | 眼睛、手、关键道具局部 |
| 俯拍/仰拍/主观 | 特殊机位单独标注 |

### 3. 视角 / 机位
- 相机高度（俯视/平视/仰视/45° 俯拍/航拍垂直）
- 相机朝向（正对/侧对/背对主体）
- 相机距离变化（即运镜，写 s 倍率区间，见 §三.12）
- 特殊视角（主观视角/从窗户看出去/监视器画面）必须写明

### 4. 镜头焦点与主体
- 这一镜观众第一眼看哪（例：篝火）
- 主体是谁/是什么（例：最前排红眼岛民 A）
- 焦点是否随台词移动（例：念到"红眼睛"时焦点切到红眼人）

### 5. 构图
- 构图类型：中心对称 / 三分法 / 对角线 / 框架式（前景框住主体）/ 引导线
- 主体在画布坐标（例：篝火中心 (540, 620)）
- 留白位置与用途（例：左 1/3 留天空，放月亮）
- 前景遮挡元素（例：左下角一截码头栏杆，增强深度）
- 视线引导（例：人群视线统一看向右侧门口）

### 6. 画面构成（四层，从远到近，逐层写全）
- **背景层**：天空/墙面/底色渐变的两端 hex、地平线 y、月亮或光源的位置/半径/hex、星星或纹理的数量与分布、海面/地板/墙面细节
- **中景层**：主体场景元素（岛体/码头/桌子/门/床）的中心坐标、rx/ry 或宽高、填充 hex、描边 hex、自带动画周期
- **人物层**：分排列表（§五 人数规则），每排逐个：x 坐标、y 坐标、身高、衣色 hex、眼睛颜色、姿态、表情、视线方向
- **氛围层**：暗角强度（%）、颗粒/噪点透明度（%）、蒙版色值与时间窗、光晕半径

**层间遮挡关系必须写明**（例：火苗底沿高于前排人头顶 ≥30px；月亮不被任何元素遮挡；人不出画）。

### 7. 光影
- 光源位置与方向（例：月光从左上 45° 打下来）
- 光线类型（硬光/柔光/轮廓光/顶光/背光剪影）
- 阴影（有/无、方向、长度、透明度）
- 特殊光效（眼睛发光、窗口灯光、水面反光带、篝火暖光范围）

### 8. 色彩基调（情绪）
- 本镜主色调 + hex（例：深蓝夜幕 `#0E2740`）
- 辅助色 + hex
- 强调色 + hex（用于焦点元素）
- 情绪目标（压抑/紧张/豁然/温暖）一句话

### 9. 元素清单（人物 + 道具，逐个列全）
每个元素一行：名称 / 类型（人物/道具/环境）/ 坐标 / 尺寸 / 形状 / 填充 hex / 描边 hex / 透明度 / 是否自带动画（周期）。
> 有生命周期的：写"第 n 句开始出现"或"第 n 句消失"。
> **已入库资产可用资产库 ID 引用**（`char/岛民_害怕`、`scene/海岛夜`、`prop/篝火`），写 ID + 坐标即可；资产库外的元素必须把要素写全。资产库清单见 `20 素材_只读/资产库/`（在建）。

### 10. 角色表演
每个在场角色一行：表情（平静/害怕/震惊/得意/恍然大悟/呆滞）、姿态（站/蹲/走/坐/摊手/发抖/举手）、走位（第 n 句从哪移到哪，坐标→坐标）、视线（看向谁/哪里）。

### 11. 逐句动作表（一句一行，不许空行）
三列：
| 这句开始 | 这句里发生 | 这句结束 |
|---|---|---|
| 画面起始状态（元素位置/表情/焦点） | 谁做什么动作（带起止秒）、哪个元素怎么变 | 画面结束状态 |

- 台词里出现的名词必须对应画面元素出现或动作（例：念"两百个人"→ 人群阵列出现并向外扩展）。
- 锚点词（`W("xxx")`）必须是台词真实存在的字（`_wcheck.py` 验）。

### 12. 运镜
- 类型：推（s 1.04→1.12）/ 拉 / 横移（左→右，位移像素）/ 上移下移 / 定格
- 必写 s 倍率区间；移动方向写清从哪到哪（例：从左到右 120px）
- 一镜 ≥15 秒：必须拆成 2~3 段运镜（如"先推后横移"），并写明每段起止秒
- 运镜与台词绑定（例：念"走进来"时镜头跟着人横移）

### 13. 转场与过渡
- 进场：上一镜怎么到这镜（硬切 / 黑场 0.2s / 雪花噪点 0.3s / 白闪）
- 出场：本镜怎么走（硬切到下一镜 / 定格 1.2s）
- 默认一律硬切；雪花噪点只用于剧情点（模拟信号/记忆/电视画面）
- 写清有没有叠化（本项目禁用叠化，转场两段分别生成后期剪）

### 14. 音效提示（与 timeline `sfx` 字段一一对应）
一行一条：第 n 句台词 → 触发什么音效（水声/心跳/敲门/剪刀/硬币落地/入水/信号噪点/海风/篝火）→ 建议音量档（强/中/弱）。
> 台词提到动作名词时必须配音效（例：念"跳了下去"→ 入水声 + 水花声）。

### 15. 文字与字卡
- 画面内模型一律不写字（prompt 以 `no text` 收尾）。
- 需要显示的字（编号、数字、字卡、标题）由引擎后期叠，写明：内容 / 字号 px / 颜色 hex / 位置 (x,y) / 出现句数 / 动画（浮现/滚动/抖动）。
- 字幕安全区按 §一执行；有 camera 只排 ≤990。

### 16. 连续性（与前镜/后镜衔接）
- 人物服装/位置/表情是否承接上一镜结束状态（例：上镜人站在码头，本镜人已在海面——中间怎么过去的要写过渡）
- 道具状态承接（例：剪刀上镜在手上，本镜必须在同一只手上）
- 同一角色在相邻镜的坐标不突变，除非有明确转场（黑场/硬切）

### 17. 出画 / 入画方向
- 每个有进出的元素：从哪条边进入/离开（上/下/左/右），速度（快/慢）
- 元素出画会被体检工具标记，若是有意出画请写明"有意"

### 18. 颜色清单（一张总表）
按用途分组列出本镜全部 hex：背景组 / 人物组（衣、眼）/ 道具组 / 光效组 / 文字组。禁止出现清单外的颜色。

### 19. 状态
`待签收` / `已签收 YYYY-MM-DD`

## 四、硬约束（每期照抄）

1. **模型不许写字**：prompt 一律以 `no text` 收尾；编号、数字、字卡全部由引擎后期叠。
2. 文字底边 **≤1104**；该镜有 camera 时只排到 **≤990**，否则压第一条字幕。
3. 动效锚点必须是台词里真实存在的字；改台词必跑 `_wcheck.py`。
4. **底色深浅自选、期内统一**：每期选深色系或浅色系（剧情镜可深、推演镜可浅），但**同一期内风格统一**，不在一镜内混深浅；深底用浅字、浅底用深字，保证对比度（WCAG 级：正文对比度 ≥4.5:1）。收尾镜不换底色系。
5. 人不出画、不压字幕区；地平线以下的腿脚不能被字幕盖住。
6. 人数规则（§五）是硬约束，台词人数 ≠ 画面人数。
7. **顶部安全区**：关键元素（人脸、道具、焦点）不进入 `y < 80` 顶部区（会被平台标题/UI 遮挡）；片头 0.3s 内平台水印区域除外。
8. **片尾镜（06_outro）一律用标准模板**：`outroStd`（脑子 IP 弹入 + 下期主题方块位），只写时间、台词、锚点、状态四项，不写自创画面；prompt 固定 `light background, white to pale blue, a cute cartoon brain mascot floating, minimal flat style, no text`（若本期为深色系，把底色词换成本期深色词，脑子上色不变）。
9. **生图 prompt 生成规则**：prompt 必须由本镜「画面构成四层 + 光影 + 色彩基调」直接转写，禁止出现文字、字母、数字、标点符号内容（一律 `no text` 收尾）；禁止出现与元素清单冲突的元素（写了"没有月亮"就不得在 prompt 里出现 moon）；prompt 只描述静态画面（运镜/动效由引擎做，不进 prompt）。

## 五、人数规则（画人群时照抄）

1. **台词里的人数 ≠ 画面人数**。台词说「两百个人」，画面画 **≤50** 个，用「外围淡剪影（opacity 0.55）延伸到画外」暗示更多，不许真画满。
2. **四排分层**：前排（全要素人形，能看清脸，8~12 个）/ 两侧（中景，6 元素）/ 后排（剪影，3 元素）/ 外围（淡剪影）。
3. **排内 x 等距**，y 用椭圆方程：`y = cy ± ry·√(1-((x-cx)/rx)²)`。x 接近两端（±rx）时 y 回落中线会叠人——后排/外围 x 范围内收（约 ±0.8rx）。
4. **排与排 y 分开 ≥30px**，排内间距 ≥ 人形宽度 + 4px。
5. 每人加 **±6px 确定性微差**（`sin(i*2.3)`），避免队列感。
6. 火焰/道具遮挡关系要算：火苗底沿必须高于前排人头顶 ≥30px。

## 六、逐句动作与"禁止静止"细则

- 逐句动作表一句一行；台词几句，动作就几行；句子不空，画面状态也不空。
- "动作"判定标准见 §二.2；凡是只写"字幕出现""淡入"的都算静止，退回。
- 动作要**带像素级的量**：不是"人走动"，是"人从 (300,600) 走到 (520,600)，2 秒，左右摆腿 4 次"。
- 长镜（≥15s）至少 3 段不同的大面积变化（换色块 / 换构图 / 换主体 / 换景别），不能只靠小动作或慢推。

---

## 七、转场 / 过渡细则

- 默认**硬切**（两段分别生成，后期剪，不让模型做转场）。
- 剧情点可用：黑场 0.2s（悬念）、雪花噪点 0.3s（信号/记忆/电视）、白闪 0.15s（回忆/冲击）。
- 噪点实现：引擎生成纯噪点帧叠加即可，不消耗模型额度。
- 禁止：叠化、模糊转场、模型自带的转场效果。

---

## 八、文字与字卡细则

- 画内文字一律后期叠：内容 / 字号 / 颜色 hex / 坐标 / 出现句数 / 动画，六要素齐。
- 大字卡（如封面大字"报到3就死站哪活"）不算画面文字，由交付环节做，不进 06 文档。
- 台词中需要强调的词（"只""唯一""正好"）可用字卡叠在画面焦点上，但必须写进逐句动作表。

---

## 九、音效轨规范（与混流对齐）

- 每镜「音效提示」必须写入 06 文档，并同步进 timeline.json 的 `sfx` 字段。
- 混流：旁白单独归一到 -20 LUFS → BGM 垫在旁白下方 10dB → 音效垫在旁白下方 -12~-16dB → 整体 -18.5 LUFS。
- 音效触发点 = 台词动作词的开头（词级时间戳对齐）。
- 音效素材：水声/心跳/敲门/剪刀/硬币/入水/海风/篝火/信号噪点，各期通用，放 `20 素材_只读/音效/`。

---

## 十、连续性规则

- 相邻镜同一角色：坐标不突变（除非有黑场/硬切标记）、服装颜色一致、道具在手位置一致。
- 时间线递进（晚上→白天）：背景色渐变要有过渡镜，或在转场处写"黑场后已入夜"。
- 每期结尾对账时，检查所有角色的「首次出现镜 → 最后一次出现镜」全程坐标/服装无冲突。

---

## 十一、签收流程

```
剧本定稿 → 05_剧本.md / 06_画面绘制.md（按本规范 19 项写） → 用户签收（改到满意）
        → 冻结画面（才允许写 scenes.js）→ 配音 → 时间轴 → 渲染 → 混流 → 交付
```

- 签收后改台词 = 作废整份画面文档，重新签收。
- 06_画面绘制.md 是画面的**唯一真相**：scenes.js 必须逐镜对账（§十三），对不上 = 未完成。

## 十三、对账表与体检（写 06 文档的人必须做）

- 文档末尾附**对账表**：文档项 → scenes.js 具体调用 → 状态（已实现/待实现/放弃+理由）。
- 体检顺序：`_wcheck`（锚点）→ `_gcheck`（字幕安全区）→ `_check`（console/越界）→ 逐句抽帧肉眼核对 → `_overlap`（文字互压）→ `_alive`（最长静止）。
- 任何一处"文档写了、代码没做"，必须以对账表形式暴露，不许静默跳过。

## 附录 A · 完整分镜示范（NO.17 钩子镜，按 19 项全写）
