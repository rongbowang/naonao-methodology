# 交接提示词 · 脑脑不老佬

> 把下面代码块里的全文复制给新会话，作为第一条消息。它会让新窗口先读交接文档，再动手。

```
你在接手「脑脑不老佬」这条短视频生产线。工作目录 \\192.168.1.3\Naonao（本机也映射成 Z:）。

【第一件事】先完整读 01 操作手册/交接文档.md。那份文档自包含，读完就知道环境、目录、
每期怎么做、以及 18 条踩过的坑。不要凭印象直接动手，这个项目的管线换过两次（manim → SVG 渲染），
旧文档已归档到 99 归档/_旧交接_2026-11-02/，里面的做法全部作废。

【这条线是怎么做的】
每期视频不是剪辑出来的，也不是文生视频。它其实是一个网页：
30 制作/<期>/web/js/scenes.js 里用 SVG + CSS + 原生 JS 把每个画面写死，
update(ctx, t, shot) 是 t 的纯函数（无状态、无动画循环）。
然后用 puppeteer 开 Chrome，逐帧 window.__seek(t) 截图，ffmpeg 拼成 mp4。
配音走 MiniMax 付费 TTS（深夜电台男声，语速 1.16），按句合成，时间码取 timestamped_words
的绝对字符位置归行。
所以画面精确到帧、改一个动作只改一行代码；代价是每句台词都要自己设计一组动作，工具省不掉。

一期完整链路（详见交接文档第 3 节，11 步）：
立项（newep.py 派生 web 工程）→ 调研 → 写 script.py（台词唯一真源）
→ check_style.py + _review.py 双检 → 写 06_画面绘制.md（19 项分镜，动手前必须写完）
→ gen_cues.py + tts_whole.py 出配音 → gen_timeline.py + build_voice.py
→ 写 web/js/scenes.js → 七个体检（_check / _overlap / _gcheck / _dupcheck / _wcheck / _alive / _outro）
→ render_all.py 一键渲 + 混流 + 交付 → _covers.py 出 30 张封面候选 → _archive.py 归档

【我这一轮做了什么】
把 11 月 1 日到 6 日的六期（NO.18~NO.23）按画面绘制规范第四版全部重做了一遍，
加上 10 月 31 日的 NO.17 已出片，现在七期都交付了：
30 制作/<期>/30_交付/ 和 40 出版物/<发布日>/<期>/ 各一份，
每份四件套 = 成片 NO.xx_<标题>_竖屏.mp4（1080×1440 / 30fps / H.264+AAC）+ 三比例封面 + 标题与描述。
每期 06_画面绘制.md 末尾加了「附录 C · 本轮画面修正记录」，逐条写明哪一镜、什么问题、怎么改的；
七期文案都补了「七、话题与标签」（抖音 10 / 小红书 8 / B站 6~7）。

主要修的画面问题（都是抽帧看出来的，不是猜的）：
· NO.22 / NO.23 的主角根本没有手（islander 的 handL/handR 被 opacity:0 藏掉了，14 处），
  人变成「圆头+圆角矩形」的方块，剪刀悬空、蒙眼摸硬币没有手 → 全部恢复并把手抬到躯干中部
· NO.23 的蒙眼布是歪的、右端戳出头部轮廓（被加了 rotate(-4)、宽度只有头径 1.12）
  → 改 1.30 宽、水平居中、不旋转
· NO.22 / NO.23 的人站在桌沿上方（俯视桌面和正面站姿透视打架）→ 藏腿改半身像
· NO.18 的 25 个编号压在人物头上（19 号整个人被挡住）、环上左右间距不均、3 号出局后编号消失
  → 编号改沿径向外推、圆形排布改按弧长等分、3 号保留并加红斜杠
· NO.21 守卫头顶被门槛横穿 → 守卫整体下移

封面这一块我重构过：原来 _covers.py 只跑 A/B/E/F/G 五个版式，而这五个恰好全是纯文字排版，
所以看起来「全是字」。模板里其实早就有 P 上图下文 / Q 出血大图 / R 左右分栏 / S 证物卡 /
T 数字出血 五个图形参与构图的版式，只是没启用。现在全部启用，每期出 30 张（10 版式 × 3 比例：
竖 1080×1440 / 横 1440×1080 / 16:9 1920×1080），总览页在根目录 封面候选_总览.html。
另外新画了 5 个题材图形（一圈人 / 硬币堆 / 格子少一格 / 蒙眼布 / 两扇门），重画了 crowd。

【现在唯一悬着的事】
七期的封面还没定稿。用户要从 30 张里挑一版。你接手后先问一句「封面定了吗」，
定了就跑：python "02 工具/_cover_finalize.py" NO.xx
它会把选中的版本改名成终选三比例，同步到 30_交付/ 和 40 出版物/，其余候选移进 99 归档/。

【开新一期怎么做】
照交接文档第 3 节的 11 步走，从「① 立项」开始。特别注意：
· 动手画之前，06_画面绘制.md 的 19 项分镜必须先写完（这是硬流程，用户要看的）
· script.py 是台词唯一真源，改了台词必须从 gen_cues.py 重走全链
· 改了 scenes.js 必须先挪走 web/_seg/，否则断点续跑会拿旧段合出「改之前」的画面
· capture.mjs --worker 只能串行（8130 端口），并行会假成功
· 每期必跑 _outro.py（漏 brainImgPlay 就是一个不动的脑子，前六个体检都查不出来）

【工作方式】
回复要短，不要开场理论。两条路都可行时不许问，都做完摆出来让他挑。
他说「要睡觉 / 不要问了」= 一路做完再报，中途不许打断。
审片会一次性列十几条带时间戳的问题，逐条对账。极反感取巧糊弄，宁可慢不要假。
```
