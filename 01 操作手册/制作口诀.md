# 制作口诀（画面 + 谜题）· 从 MEMORY.md 拆出来的细则

> MEMORY.md 只留指针，全文在这里。改规则改这里，MEMORY 里的摘要同步改。

## 一、画面生动性（优先级最高）

### 六个体检，缺一个就漏
`_check.mjs` 元素数/出画/报错 · `_overlap.mjs` 文字互压+压字幕 · `_gcheck.mjs` 图形出画+压字幕 ·
`_dupcheck.py` 画面文字复读字幕 · `_wcheck.py` 锚点是否真的匹配 · **`_alive.py` 这十几秒有没有在动** ·
`_deadshot.py` 死的那几秒是哪一镜。
**判据：最长静止 ≥4.0s FAIL、2.0~4.0s WARN。** 参考片（墨有意思）3.5s / 38%。

### ★ 小动作没用，面积才有用
`_alive` 量的是 108×144 缩略图平均差：5px 波纹、10px 气泡、1.02 倍呼吸**全量不出来**。
有效性排序：① **大面积扫光**（`stage2` 自动挂）② **数字滚动**（大字从 0 滚到目标）③ **粗环/粗线呼吸**
④ **整排变暗/整块填充**（clipPath 从左往右揭开）⑤ ~~细线移动、小圆点~~ 无效。

### 背景三层光（`bgmotion`，场景零改动）
`stage2` 建灯、`cam` 每帧驱动：游走主光（r=380/0.09）+ 反向扫光（900px/0.045/4.8s）+ 整屏呼吸（0→0.036/5.2s）。
**光画在背景 rect 之后、内容之前**，亮度上限卡 0.07。⚠ 没用 `stage2` 的期吃不到（得用 `_patch_lights.py`）。

### 人形画法四条
① 圆角肩**闭合躯干**（底边封口当脚）② **肩明显比头宽（1.55 倍）**——能不能读成「人」的唯一关键
③ 手画**实心小圆**垂到髋部（空心圆读成扣子）④ r ≈ 0.09×画布高，**必须加地平线**。
**倒地的人**：椭圆躯干 + 圆头 + 一伸一屈两条腿 + **两只脚**。`nod()` 绕脖子转（`headY+0.9r`）。

### 动作要「三段式」咬台词点
举起 → 悬停憋住 → 在目标那一拍落下。**打击点必须和台词点咬在一起**。

### 抽象形状必须有「载体 + 动词」
台词说「点头/堵回来/一撕两半」，画面就得真点、真堵、真撕。画「纹理/符号」要坐实载体和语境。

### 参考片「墨有意思」八招
量化：mean 3.02 / 静止 38% / 最长 3.5s；**硬切只有 6 次，连续 61.5 秒不切镜**——靠镜内元素变化造节奏。
① 一个角色一条**姿态线** ② **一块分格道具从头用到尾，状态迁移=叙事推进**（最值钱）③ 量化道具贯穿
④ 仿真 UI 当戏道具 ⑤ 一处光源 ⑥ 深棕纹理底 ⑦ 出处打底部 ⑧ 章节卡。
**不能照抄**：它没旁白，画面文字承载 60%；我们有旁白+字幕，画面文字必须让位。
借「角色/道具/状态迁移/量化道具」，不借「大标题铺满 + 暖棕木框」。

## 二、画面验收的固定坑

- **字幕安全区**：画面文字底边 ≤ **1104**，可用区 y ∈ [200, 1104]；开 camera 放大后只排到 y ≤ 990
- **`W(shot,i,"词")` 匹配不到会静默失效**（元素永不显示、渲染不报错）→ 每次改台词必跑 `_wcheck.py`
- **`LB(shot,i)` 越界会被夹到最后一行**，整段动画压到句末爆发
- **`_overlap.mjs` 豁免**：故意的重叠用 `data-ok-overlap="1"`（**压字幕永不豁免**）
- **`_gcheck.mjs` 两闸**：宽≥1020 或高≥1380 算出血；压字幕阈值 **1140**
- **`_shot.mjs` 打开 index.html 必须带 `?capture=1`**；`--t 52 --o _prev.png` 截帧后用 Read 看图，**改画面先看图再整片渲**
- **`_shot.mjs`/`_gcheck.mjs` 不在 newep 的拷贝清单里**，新工程要手动从 `_webtmpl` 补
- `glow` 半径收 **262~300**（camera 1.1 倍后 r=330 实际 370，边界必出画）
- **会动的组在 build 阶段就要有初始 transform**，否则 `_check` 按 (0,0) 量出画
- **原地缩放只有 `translate(vx,vy) scale(sc) translate(-cx,-cy)`**；写两次 translate 会把元素甩出画面
- **场景名以 `script.py` 的 `scene` 字段为准**（`TurntableScene`→`define("turntable")`）。
  写错报 `Cannot read properties of undefined (reading 'build')`
- **`K` 是 kit.js 的原子（K.sp/K.seg），不是 LIB**；LIB 函数要先解构
- **`K.txt()` 是 HTML div，塞进 `<svg>` 不显示且不报错** → svg 里用 `<text>`（自己写 `svgText()`）
- **`gpop()` 会重写 transform**（以 0,0 为锚），build 里设过 transform 的元素出场必须手写 `opacity + transform`
- **`gpop()` 写的是 `style.opacity`**，只设 attribute 会被盖住且不报错
- **概率曲线「一根线在长」活动率极低** → 曲线下铺填充区用 clipPath 揭开

## 三、片尾脑子（账号符号，每期都用）

**用图片，不用 SVG**（用户：「我想要的就是这个一模一样的形状」）。素材 `_webtmpl/assets/brain_ref.png`。
**别动** `brain_ref.png`。老工程没有 `web/assets/` → `brain_ref.png` 404 → 脑子画不出来且不报错，
只在 `_check.mjs`「加载失败的资源」露一行（`sim.js` 那条是可选的，忽略）。
- 抠图：非白像素当本体 mask → `MaxFilter(19)` 膨胀 9px → 自造白边 → 两层合成
- API：`brainImg(svg,cx,cy,w)` + `brainImgPlay(B,tl,t0,{mode,dim,dimTo})`，mode = `pop`/`beat`/`shine`/`sway`
- `dim` 必须接受**数组**（`ctx.crowd` 是数组），否则静默跳过

## 四、谜题 / 数理推理型

**知识科普**：我告诉你一个事实，你点头。**谜题**：我给你一个条件，你自己想答案。
区别在观众的姿势——一个是听，一个是想。**第一秒他就已经参与进来了。**

### 选题四关（任一不过就换题）
① 规则一句话讲完（≤15 秒）② 答案是一步（一个动作）③ **观众手边有东西能试**
④ 答案能三句话转述给朋友。第 ③ 条最容易被忽略。NO.14 密立根四关全不过 —— 选题阶段就该拦。

### 九段式（2026-10-30 定）
处境 13% → 规矩 10% → **立靶 10%**（观众自己说出错答案）→ 背书 8%
→ **绝望 16%**（证明这根本做不到）→ 转折 6%（报出要几步）→ 破执念 10%
→ 解法 22%（带数字验算，**再换个数字验一遍**）→ 收尾 5%。
**我们历史上几乎没做过第 ⑤ 段**，一上来就讲机制，所以答案是「轻」的。**选题必须能填满 ③ 和 ⑤。**

### 三种收尾
A 落到今天会做的一件事 · B 落到一门学问的名字 · C 落回「你的直觉为什么不可靠」。
判据：关掉视频能不能三句话讲给旁边的人。

### 数字要「数出来」，不要「打出来」
观众的验证感来自能用手指数。我们的「117 条」是打上去的，只能信不能验。

### 四个技术坑
1. **`stroke-dasharray` 必须精确 = 路径长度**，用 `getTotalLength()`，估的值全错
2. **虚线不能既当样式又当「逐段画出」**：要生长就改半径
3. **纸上的洞必须有洞底**（只挖空会透出背景，像贴了个深色圆盘）
4. **`K.txt()` 是 HTML div，塞进 `<svg>` 不显示**

### 抖音取素材（反爬很硬）
`aweme/v1/web/aweme/detail` 403（Argus 签名）；分享页是空壳。
**能用的是 puppeteer 打 `www.douyin.com/video/<id>` 取 `<video>.currentSrc`**。
工具 `_dy_grab.mjs` / `_dy_video.mjs`；ASR 用 `AudioTranscribe`。


## 六、画幅与换算（2026-11-03 起 16:9 是主线）

**唯一开关是 `web/size.json`**：`gen_timeline.py` 读它写进 `timeline.json` 的 width/height，
`kit.js` 的 `K.VW/K.VH` 从 `timeline.json` 拿，`capture.mjs` 的 viewport 也从这里来。
所以**只改 size.json + 重跑 gen_timeline 就换画幅**，时长和逐句时间码完全不动。

| 画幅 | size.json | 字幕 | `SAFE_BOT` |
|---|---|---|---|
| 竖屏 3:4 | 1080×1440 | CSS 兜底：920 宽 / 45px / 底 118 | 1104 |
| 横屏 4:3 | 1440×1080 | engine 注入：110 边距 / 46px / 底 84 | 760 |
| **横屏 16:9** | **1920×1080** | engine 注入：180 边距 / **50px** / 底 90 | 760 |

### 换画幅的四条硬规矩
1. **纵向不动**。高度不变时（1080→1080）地平线、球心、桌沿全部沿用 —— 那是节奏，不是比例。
2. **横向靠「变大」补，不靠「留白」补**。1440→1920 多出来 480px，全部交给主体放大 1.1~1.25 倍 + 往画心挪；
   留空边 = 观众第一眼觉得「没铺满」。
3. **放大必然下压**：半径 +10 就把球底往下顶 10px。凡是放大过的圆，圆心同步上移同等像素，保证 bottom ≤ 760。
4. **居中要重新验**。4:3 里偏左 100px 看不出来，16:9 里同样的偏移整片左塌。
   算法：`|主体中心 − K.CX| > 60px` 就重排。**这条是抽帧才发现的，预检脚本查不出来。**

### 换完必须重跑
`gen_timeline.py` → `_bbox.mjs --n 12`（压字幕 0 才算过）→ `_alive_pre.mjs`（< 4s）→ 抽 7 帧用眼睛看
→ `render_all.py`（渲染前把 `_seg/` 挪走，否则断点续跑拿旧段合出旧画幅）。
交付文件名由 `size.json` 自动判断 `_横屏.mp4` / `_竖屏.mp4`（`render_all.py` / `_archive.py` 都改了）。


## 七、开场与倒计时（2026-11-03）

**推理/谜题类不许用钩子句式**，上来直给：场面 → 人物规则 → 你的限制 → 逼问 → 「给你三秒钟」。
然后 3 秒倒计时：画面大数字 3/2/1 逐格压下来 + 背景绕画心转 3°，配音只出三声鼓点（`boom-hit-soft`，间隔 1.0s），**不念数字**。

落地分三步：
1. `script.py` 写 `COUNTDOWN = {...}`（声明在第几镜之后、几拍、每拍多久、用什么音效）
2. 配音：`voice.wav` 在该句之后插 3.0s 静音，`timeline.json` 把后面的句子整体后移 3.0s
3. 作画：这 3 秒要当成一镜来设计 —— 数字 + 转场 + 鼓点三者必须同拍

**台词里绝对不许出现编排话**（先说规矩 / 下面我们分三步 / 先说结论）。`check_style.py` 已设硬 FAIL。


## 八、角色画法（2026-11-03，NO.21 返工四轮）

人形只要缺两样，观众就读不出来：**脸**（眼球+高光+眉+嘴）和**手**（腕上一个实心圆）。
手臂色必须比衣服亮一档，否则整条手臂被身体吃掉，只剩两个橙点。

- **头发**：先画发球（比脸大 3~4px），再画脸并下移 2~3px。脸圆盖住发圆 = 秃头。
- **胡子**：八字胡 + 下巴胡分两件，中间留嘴。一整把盖住下半脸 = 没表情。
- **恶龙这类复杂生物**：不要手写一条大闭合路径（头没形状、骨刺飘出轮廓、改一处牵连十处）。
  改**部件拼装**——身体椭圆 / 脖子弯管 / 头圆 / 吻梯形 / 腿圆角柱，两两重叠 ≥20px 埋接缝。
  沿轮廓排布的装饰（骨刺、鳞片）用公式取点，不要手写坐标。
- **验图尺寸**：按成片里的实际大小截图（s≈1.15），别放大 2 倍 —— 放大看的是成片里根本不存在的接缝。
