# 音效库（325 个，CC0）· 2026-10-23

> 来源 **wyzowl/sfx-kit**（GitHub，CC0-1.0，`48kHz / 24bit WAV`）。
> 可商用、可改、**无需署名**（署名 wyzowl 表示感谢）。
> 索引文件：`工程文件/sfx_catalog.json`（每条含 sync 点、响度、用途、反面用途）。

## 怎么用

```js
// 场景 build 里登记（update 里会每帧重复，不要放那里）
sfx(box, W(shot, 1, "两年"), "impact-soft", 0.6);
```

**tl 是「动作该发生的那一刻」，不是音效起点。** `mux.py` 会按每个音效自带的
`sync_at` 把起点提前，让**峰值正好落在动作上**。这条比什么都重要 ——
「动作开始了才听见声音」和「声音和动作同时到」是两种观感。

响度：所有音效先归一到 `-19 LUFS` 再乘 `vol`，所以不同音效写同样 `vol` 得到的
实际响度是一致的（老素材 whoosh 是 -12.2、ding 是 -17.6，差 5.5dB，以前写同样 vol 会一炸一闷）。

## 选音效的三条判据

1. **看屏幕在发生什么，不看你想表达什么情绪**。库里每个音效的 `use_for` / `avoid_for` 就是按屏幕事件写的（`Whip pans` / `cards flicking in or out`）。
2. **看时长**。`fits_seconds` 给了它能配多长的时间窗口；动作只有 0.2 秒却配 1 秒的音效，尾巴会拖到下一句台词上。
3. **别铺满**。一期 8~10 个点足够。每个转场都放 whoosh，第三次观众就听出来了。
